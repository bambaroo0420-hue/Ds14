TEM GT Studio v1.1SAM · Superpixel · Normal DP · Ground Truth

1. 이미지 / 프로젝트

이미지 전환 전 작업을 저장하세요. 서버 종료 시 메모리는 지워집니다. ZIP을 다시 열어 편집을 이어갑니다.

2. 층과 편집

휠: 커서 중심 확대 / 이동 모드·가운데 버튼: 이동. Polygon·계면선은 클릭으로 추가. Enter: polygon 적용.

3. SAM / micro-SAM

모델 설정선택 패키지·가중치 필요. 자동 다운로드하지 않습니다.
일반 모드: 점들이 한 객체를 지정. 배치 모드: 각 양성점이 별도 객체(음성점 미사용). 다른 층은 class를 바꿔 따로 실행합니다.

4. Superpixel 보완

생성 후 Superpixel 모드에서 클릭·드래그. 크기를 줄여 ROI 재분할해도 기존 GT는 유지됩니다.

5. 법선 방향 경계 보정

초기 위치 거리 페널티 없음. 선 모드는 ROI 안에서 선의 왼쪽=선택 층, 오른쪽=반대 층으로 분할합니다. 선은 ROI를 가로질러 그리세요. mask 모드는 비워진 부분을 반대 class로 채웁니다. 적용 후 반드시 확인하세요.

6. 스케일바 / 문자 제외

EasyOCR · CPU · 자동 다운로드 OFF스케일 미확정 (픽셀 GT 제작 가능)OCR 누락은 편집 동작 '학습 제외' + polygon/brush로 보완하세요. 배율 숫자는 nm/px 환산에 사용하지 않습니다.

7. 표시 / 저장

원본 해상도. edge=1 / valid=1. 제외 영역은 두 loss와 평가에서 모두 무시해야 합니다.
이미지를 열거나 합성 예제를 눌러 시작하세요.
