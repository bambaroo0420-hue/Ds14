# TEM semantic·boundary GT 제작 설계

작성: 2026-09-28. 갱신: 2026-09-28, 개정 2. 상태: 구현 전 설계 정리.
아래에서 ‘확정’은 사용자와 합의한 내용, ‘제안’은 이번 검토에서 추가한 내용이다.

## 1. 목적과 확정 파이프라인

TEM 원본 → 스케일바·문자 검출 및 스케일 환산/제외 영역 확인 → micro-SAM / superpixel / 수동 편집 → coarse semantic mask → initial boundary → 법선 방향 ±5~10 px 탐색 → gradient/contrast 후보 점수 → dynamic programming(DP) → refined centerline → 사용자 확인·수정 → semantic GT와 edge GT 분리 저장.

이 문서에서 boundary GT와 edge GT는 같은 출력이다. 경계 중심선은 별도의 좌표 데이터로 보존한다.

SAM 결과를 그대로 정답으로 확정하지 않는다. 최종 GT는 사람이 원본 TEM에서 확인한 계면을 기준으로 생성한다. 현재 우선순위는 GT 제작과 경계 보정이며 두께·RMS 계측은 후속 기능이다.

## 2. 확정 사항

| 항목 | 정의 |
|---|---|
| 탐색 방향 | 초기 경계의 국소 법선 방향 |
| 탐색 범위 | 초기 경계에서 양쪽 ±5~10 px |
| 계면 위치 | 최종 보정·확인한 가운데 중심선 |
| 경계 선택 | 가장 강한 gradient peak를 우선하되 경로 연속성을 고려 |
| 주의점 | 연속성이 강해 강한 peak로 이동하지 못하는 현상을 피할 것 |
| Semantic GT | 최종 중심선을 기준으로 영역을 채운 층별 class 라벨 |
| Boundary centerline | 최종 계면 위치를 보존한 선 |
| Boundary GT | 중심선 양쪽 1 px, 전체 약 3 px 폭의 학습용 경계 띠 |
| 픽셀 기준 | 화면 표시 배율이 아닌 원본 이미지 해상도 |
| 계측 기준 | 추후 계측에는 경계 띠의 가장자리가 아닌 중심선 사용 |

경계 띠는 물리적 계면 두께를 뜻하지 않는다. 위치가 모호할 수 있어 둔 라벨 폭이다. 대각선·곡선은 래스터화 방식에 따라 폭이 달라지므로, 구현 시 거리 기준과 팽창 커널을 명시한다. 경계 띠 생성과 평가 허용거리는 별도로 정의한다.

## 3. DP 구현 제안

- 초기 위치에서 멀어지는 것 자체에 주는 거리 페널티는 기본 0으로 둔다. 탐색 ROI가 이동 범위를 제한한다.
- 각 법선에서 peak 후보를 여러 개 유지하고 DP로 최종 경로를 선택한다.
- gradient 우선, 약한 연속성 페널티를 기본으로 한다. 점수 정규화와 가중치 정의는 구현 때 명시한다.
- 연속성 0에서는 법선별 최대 gradient 선택 결과를 확인할 수 있게 한다.
- 연속성은 이웃한 점의 급격한 위치 변화를 억제한다. 초기 경계와의 거리 페널티와 혼동하지 않는다.
- 연속성 가중치가 양수이면 일부 지점에서 최대 peak 대신 다른 후보가 선택될 수 있다. 모든 지점 최대 peak와 매끄러운 경로를 동시에 보장하지 않는다.
- contrast를 추가하면 gradient 최대와 합산점수 최대가 달라질 수 있으므로 별도 on/off와 가중치를 둔다.
- 초기 경계, 법선별 최대 peak, DP 결과를 개별 토글 표시한다.
- 경계 전체 이동을 막는 초기 위치 고정은 피한다. 사용자 고정점은 별도 명시적으로 설정한다.
- 너무 강한 평활화는 실제 거칠기를 없앨 수 있으므로 보정 강도를 기록한다.
- 진짜 계면이 탐색 범위 밖이면 ROI 확대 또는 초기 경계 수정이 필요하다.
- 신호가 모호하거나 인접 계면으로 점프한 구간은 자동 확정하지 않고 검토 대상으로 표시한다.

## 4. SAM 영역 지정: 공식 동작과 제안 구분

micro-SAM 공식 2D annotator 문서에서 일반 point 모드는 한 객체를 지정한다. 여러 양성점은 같은 객체를 설명하는 프롬프트로 쓰인다. batched 모드는 양성점 하나당 별도 객체를 분할한다. 양성점 자체가 재료명이나 semantic class를 의미하지는 않는다.

따라서 n개 층에 양성점 n개로 시작하는 방식은 가능하지만, 각 점을 별도 객체로 처리한 뒤 층 class를 부여해야 한다. 한 점으로 원하는 층이 항상 분리되는 것은 아니다.

### 제안하는 UI 및 데이터 구조

1. 층 목록에 class 이름과 색을 등록한다(예: 층 A, 층 B, passivation).
2. 각 영역에 class_id와 instance_id를 별도로 부여한다.
3. 양성점 하나로 시작하고 mask를 미리 본다.
4. 실패한 객체만 선택해 box + 양성점 + 인접층 음성점으로 개별 수정한다.
5. 필요하면 실제 crop으로 국소 추론한다. box prompt만 주는 것과 crop 추론은 다른 기능이다. crop 좌표는 원본 좌표로 복원한다.
6. 그래도 실패하면 polygon/brush로 coarse 영역을 만들거나 대략적인 계면 polyline을 직접 그려 경계 보정 단계로 넘어간다.
7. DP 보정 후 사용자 확인을 거쳐 GT를 저장한다.

class별 관리, 객체별 편집 전환, 직접 경계 입력은 프로젝트용 통합 UI 제안이며 micro-SAM 기본 UI에 모두 이미 구현되어 있다는 뜻은 아니다.

## 5. 같은 층이 다른 셀에 반복될 때

예: 셀 3개 각각에 층 A/B가 있으면 class는 2개, 분리된 대상 영역은 6개이다.

| 영역 | class_id | instance_id 예시 |
|---|---|---|
| 셀1의 층 A | A | 1 |
| 셀2의 층 A | A | 2 |
| 셀3의 층 A | A | 3 |
| 셀1의 층 B | B | 4 |
| 셀2의 층 B | B | 5 |
| 셀3의 층 B | B | 6 |

분리된 영역은 각각 프롬프트로 지정하는 것을 기본으로 제안한다. 같은 class의 instance들을 semantic GT에서는 같은 class 값으로 저장한다. 연결된 하나의 막이면 여러 셀을 가로질러 한 mask로 잡힐 수도 있다.

한 셀을 클릭했다고 다른 셀의 같은 재료를 자동으로 의미적으로 찾는다고 가정하지 않는다. 자동 mask 생성도 원하는 층 분리와 class 부여를 보장하지 않는다.

클릭 수 감소를 위한 후속 제안: 대표 셀에서 지정한 프롬프트를 다른 셀의 정렬된 위치로 복사하고, 각 셀에서 mask를 새로 추론한 후 검토한다. 셀 검출·정렬이 별도로 필요하며 두께·모양 변화가 크면 수정이 필요하다. 첫 버전은 객체별 클릭 방식으로 시작한다.

## 6. 흐린 계면 처리 원칙 — 제안

- 점은 대상 선택을 돕지만 영상에 없는 경계 정보를 만들어내지는 않는다.
- 초기 경계가 실제 계면 ±5~10 px 이내에 있으면 SAM 경계가 정밀하지 않아도 후속 보정을 시도할 수 있다.
- SAM이 두 층을 통째로 합쳐 내부 계면이 사라졌다면 외곽 경계 보정만으로 내부 계면을 만들 수 없다. 수동 분할 또는 내부 계면 polyline 입력을 지원한다.
- 사람이 판단 가능한 구간은 직접 수정하고, 사람도 불명확한 구간은 ignore/불확실 영역 표시를 검토한다. 약한 gradient의 최대점을 물리적 정답으로 단정하지 않는다.
- 3 px 띠가 더 큰 위치 불확실성을 해결하는 것은 아니다.
- 인접 층의 공유 계면은 하나의 중심선으로 관리해 두 semantic mask 사이의 중첩·틈을 막는다.
- 미주석 영역을 자동으로 배경 정답으로 취급하지 않는다. 학습 범위와 ignore 정책을 구분한다.
- 이 도구로 만든 GT로 동일한 gradient+DP 알고리즘을 평가할 때에는 자동 생성 편향을 주의한다. 독립적인 수동 검토 영역을 평가에 포함한다.

## 7. 권장 저장 항목 — 제안

- 원본 크기의 semantic class map, instance map(편집용), boundary binary map.
- 원본 좌표계의 boundary centerline 좌표 및 필요 시 래스터 mask.
- class 목록, 객체별 class_id, 프롬프트·ROI, 탐색 폭·가중치·전처리 설정.
- 사용자 확인 여부, 수동 수정 및 불확실 구간 기록.

## 8. 미확정 사항

- 층별 class 이름과 셀/층 instance 관리 UI.
- 경계 띠의 래스터화 규칙, 공유 경계 및 교차점 처리.
- gradient 전처리, contrast 사용 여부와 점수 정의.
- DP 연속성·곡률 가중치, 열린 경계/닫힌 경계 및 법선 교차 처리.
- 불확실 구간 ignore 정책과 평가 허용거리.
- 실제 TEM에서 프롬프트 수정 횟수 및 GT 제작 시간 비교.

## 10. SAM 실패 시 GT 보완 도구 — 논의 내용 및 설계 제안

세 가지 입력 경로를 공통 경계 보정 파이프라인에 연결한다: SAM mask, superpixel 선택·병합, 직접 영역/계면 그리기.

| 도구 | 역할 |
|---|---|
| 브러시·지우개 | 기존 mask에서 작은 영역 추가·제거 |
| Polygon·채우기 | SAM이 놓친 층의 coarse 영역 생성 |
| Superpixel 선택·병합 | 실패한 ROI를 작은 조각으로 나누고 같은 층끼리 선택 |
| 계면 polyline | 합쳐진 두 층 사이에 빠진 내부 계면 지정 |
| 경계점 이동·고정 | DP가 다른 peak로 이동한 구간 수정 |
| Undo/redo, 원본/overlay 토글 | 편집 복구와 원본 비교 |

micro-SAM 기본 기능과 프로젝트에서 추가 구현할 기능을 구분한다. 특히 계면 polyline → DP → semantic 재생성은 통합 구현 대상이다.

### Superpixel 사용 및 한계

- 전체 영상을 과도하게 잘게 나누기보다 SAM이 실패한 ROI에 적용한다.
- 층 class 선택 후 클릭·드래그로 여러 조각을 지정하고, 기존 mask에 추가/제거한다.
- 계면을 가로지르는 조각은 국소 재분할하거나 수동 분할한다. 재분할 시 확정한 다른 영역은 보존한다.
- 테두리와 색상 overlay를 각각 켜고 끄며 원본과 비교한다.
- Superpixel 테두리는 최종 계면이 아니다. 선택·병합한 coarse mask에서 경계를 추출한 뒤 보정한다.
- SLIC을 사용할 경우 조각 크기, compactness, smoothing을 비교한다. 작은 조각이나 낮은 compactness가 항상 정확도를 높이지는 않는다.
- 점무늬가 강하면 약한 smoothing을 시험할 수 있지만 강한 smoothing은 실제 계면 정보를 손상할 수 있다.
- 계면을 못 따라간다고 바로 학습할 필요는 없다. 부분 수정으로 GT 제작 시간을 줄이는 것이 우선이다.
- 반복적인 실패와 높은 수정 비용이 확인되면 완성 GT로 segmentation/boundary 모델을 학습하는 후속 단계로 연결한다.
- 초기 경계가 실제 계면에서 탐색 폭 이상 벗어났으면 선을 수정하거나 탐색 폭을 확대한다.

## 11. 스케일바·문자 인식 — 사용자 추가 요구 확정

### 입력 구성

이미지에 스케일바와 실제 길이(예: 50 nm), 아래쪽 샘플 정보 문자, 위쪽 배율 숫자가 존재한다. 위치를 고정 가정하지 않고 전체 이미지에서 검출하며, 예상 위치는 보조 정보로만 사용한다.

### 자동 환산 흐름 — 구현 제안

1. 원본에서 선/직사각형 형태의 스케일바 후보와 문자 영역을 각각 검출한다.
2. OCR로 스케일 길이 숫자와 단위를 읽는다. 샘플명·배율 숫자와 분리한다.
3. 거리와 배치 관계를 이용해 스케일바 후보와 길이 문자를 연결한다. 배율 숫자를 스케일 길이로 오인하지 않는다.
4. 바 양 끝점 사이 길이를 원본 px 단위로 측정한다. 테두리/눈금이 있는 경우 끝점 규칙을 명시한다.
5. 단위를 nm로 통일하고 다음 식으로 환산한다.

   nm_per_pixel = scale_length_nm / scale_length_px

   예: 50 nm / 156.25 px = 0.32 nm/px. 예시이며 실제 측정값이 아니다.

6. 검출 바, 양 끝점, OCR 값·단위, 계산 결과를 overlay와 수치로 표시한다.
7. 자동 결과 확인/수정, 수동 끝점 2개+실제 길이 입력, nm/px 직접 입력을 지원한다.

### 예외 처리 — 제안

- OCR 실패·후보 여러 개·바 잘림·단위 불명확 시 임의의 값을 저장하지 않는다. unresolved 상태로 저장하고 수동 보정을 요청한다.
- 스케일을 확정하지 못해도 픽셀 단위 GT 작성은 가능하게 한다. 물리 단위 계측은 보류한다.
- 배율 표기(예: 120k)는 메타데이터로 저장하되 그것만으로 nm/px를 계산하지 않는다.
- 문자 인식 문자열과 문자 위치 검출을 구분한다. 문자열을 잘못 읽어도 문자 박스를 검출했다면 제외 마스크는 생성 가능하다.
- 축소/확대 전 원본에서 보정값을 구한다. 등방성 resize 배율 r이면 새 nm/px는 기존 값/r이다. 단순 crop은 nm/px가 변하지 않지만 좌표 원점이 바뀐다.
- 비등방성 resize는 원칙적으로 피한다. 원본의 비등방성 픽셀 여부를 모르면 한 방향의 스케일바만으로 두 축을 독립 보정했다고 주장하지 않는다.
- OCR 도구/모델은 미선정이며 사내 오프라인 실행과 의존성 반입 가능 여부를 기준으로 추후 선정한다.

## 12. 문자·스케일바 영역의 학습 제외 — 사용자 요구 및 구현 제안

확정 요구: 스케일 길이 문자, 샘플 정보, 배율 문자 등 문자 영역은 학습에서 제외한다. 제안: 인공적인 강한 경계인 스케일바 자체와 주석 화살표/측정선이 있으면 함께 제외한다.

- 문자/스케일바 검출 박스에 조절 가능한 여백을 더해 annotation exclusion mask를 만든다.
- 자동 누락·오검출을 수정할 수 있도록 사각형/brush 기반 제외 영역 편집을 지원한다.
- 제외 영역은 ‘배경 class’ 또는 ‘edge 없음’이라는 정답으로 학습시키지 않는다.
- semantic loss와 edge loss, 두 작업의 평가 지표 모두 valid mask가 참인 픽셀만 사용한다. 유효 픽셀이 없는 patch는 건너뛴다.
- 단순히 검정색으로 덮는 것만으로는 학습 제외가 구현되지 않는다. loss/metric mask 적용을 필수로 한다.
- loss 제외만으로 모델이 문자를 입력 문맥으로 보는 것까지 막지는 못한다. 구조 밖의 문자 띠는 crop/patch sampling으로 입력에서도 제외하는 방식을 우선 제안한다.
- 구조 위에 문자가 겹치면 원본은 보존하고 해당 구간을 ignore 처리한다. 필요 시 학습 입력에서만 치환하되 복원된 실제 구조로 취급하지 않는다.
- 미주석 영역, 불확실 계면, 영상 외부 padding도 별도 사유를 기록하고 작업별 valid mask에 반영한다.
- semantic valid와 edge valid를 분리할 수 있게 한다. 한쪽 작업만 확정된 영역에 대응하기 위함이다.
- 제외 영역 테두리, crop 경계, 미주석 영역과의 경계를 edge GT로 만들지 않는다. 해당 주변에서 오염될 수 있는 edge 감독 영역도 제외한다.

## 13. 분리 저장 규격 — 사용자 요구 확정, 상세 형식 제안

Semantic GT와 edge GT는 서로 다른 파일/폴더에 저장한다. 컬러 overlay는 확인용이며 학습 라벨과 분리한다. 같은 image_id로 원본과 모든 출력이 대응하고 원본 해상도/좌표계를 일치시킨다.

| 경로 예시 | 내용 | 제안 값 규칙 |
|---|---|---|
| images/img001.png | 원본 또는 무손실 변환 영상 | 원본도 별도 보존, 추가 JPEG 압축 금지 |
| semantic_gt/img001.png | 층별 class 정수 라벨 | 0=확인된 배경, 1..N=층, 제외는 valid mask로 구분 |
| edge_gt/img001.png | 중심선 ±1 px 경계 띠 | 유효 영역에서 0=비경계, 1=경계 |
| valid_semantic/img001.png | Semantic 감독 유효 영역 | 1=사용, 0=제외 |
| valid_edge/img001.png | Edge 감독 유효 영역 | 1=사용, 0=제외 |
| centerlines/img001.json | 계면별 중심선 좌표 | 원본 x,y, 계면 ID, 양쪽 class, 확인 상태 |
| metadata/img001.json | 스케일·OCR·좌표 변환·설정 | 단위/끝점/자동·수동 여부/확정 상태 |
| overlays/img001.png | 검토용 합성 영상 | 학습 라벨로 사용하지 않음 |
| project/img001.* | 재편집용 정보 | instance, prompts, superpixel 설정, 수정 이력 |

PNG/TIFF 등 무손실 정수 라벨 형식을 사용한다. class 수에 따라 uint8/uint16을 선택한다. 제외 영역의 라벨 저장값은 placeholder이며 valid=0으로 무시한다. 모델 학습 코드에서 필요하면 semantic ignore_index로 변환한다. Edge BCE 등의 loss에는 valid mask를 명시적으로 곱하고 유효 픽셀 수로 정규화한다.

라벨에 회전/resize 등 변환을 적용할 때 class 혼합을 피하는 규칙을 정한다. 가능하면 변환한 중심선에서 edge 띠를 재생성한다. 원본에서 ±1 px라는 GT 정의와 학습용 resize 후 픽셀 폭을 구분하여 기록한다.

## 14. 추가로 고려할 사항 — 제안

1. **Class 사전 통일:** 모든 이미지에서 동일 층은 동일 class_id를 사용한다. 같은 재료라도 구분할 위치/역할이 다르면 별도 class 여부를 먼저 정한다.
2. **Edge 범위:** 초기 출력은 관심층의 확정 계면을 합친 binary edge GT로 제안한다. 계면별 ID/양쪽 class는 중심선에 남겨 추후 다중 채널 변환이 가능하게 한다. 모든 밝기 edge를 GT로 지정하지 않는다.
3. **공유 경계·얇은 층:** 같은 계면을 두 번 따로 보정하지 않는다. 두 경계 띠가 겹칠 만큼 얇은 층은 binary edge만으로 두 계면 구분이 어려우므로 개별 중심선을 보존한다.
4. **모호함 관리:** 확정/검토 필요/제외 상태를 구분한다. 경계 라벨의 ±1 px 폭보다 실제 불확실성이 크면 띠만으로 해결하지 않는다.
5. **데이터 누수 방지:** 동일 원본에서 잘라낸 patch/셀/증강 영상을 train과 validation/test로 나누지 않는다. 가능한 경우 시편 또는 촬영 그룹 단위로 분리한다.
6. **품질 검사:** 영상·GT 크기 일치, class 유효성, semantic/edge 중심선 일치, 제외 영역 처리, 원본 좌표 변환, 스케일 확정 여부를 저장 시 검사한다.
7. **중간 저장:** 프롬프트, mask, 중심선, 파라미터를 저장해 재시작 시 편집을 이어간다. 최종 학습 export와 작업 중 저장을 구분한다.
8. **효과 측정:** 이미지당 GT 제작 시간, 수동 수정 횟수, 원본에서 검토한 경계 오차를 기록한다. SAM 단독과 보완 도구 사용 조건을 비교할 수 있게 한다.
