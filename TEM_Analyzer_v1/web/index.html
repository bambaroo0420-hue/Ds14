영역 템플릿

새 템플릿은 영역 없이 시작합니다. 스케일 영역과 글씨 영역을 드래그한 뒤 저장하세요.

이미지별 스케일 설정

스케일 ROI 지정 → 바 검출 → 실제 길이 입력 → 계산·저장. ROI의 너비가 아니라 검출한 바 길이를 사용합니다.

바 길이: 미지정

OCR 보조 (선택 사항)

OCR 없이도 바 검출 + 실제 길이 입력으로 계산할 수 있습니다. OCR은 저장한 템플릿 ROI를 사용합니다.

스케일 미확정

전체 이미지 일괄 적용·검수

현재 템플릿과 드래그한 영역을 저장해 적용합니다. 위 실제 길이·단위를 모든 이미지에 공통 사용합니다. 바에 적힌 길이가 다른 이미지는 개별 수정하세요.

    원본은 보존됩니다. 적용한 영역은 분석용 이미지에서 검정색으로 채우고 SAM 결과에서도 제외합니다. 기존 후보는 유지하며 새 분할부터 반영됩니다.

    이미지상태바 길이(px)실제 길이px/nmnm/px스케일/글씨 ROI 수제외 px

    분홍색=분석 제외 영역, 주황색=스케일바. 검출 실패는 수동 스케일 저장 후 확정하세요. 템플릿 수정 후 다시 적용해야 분석에 반영됩니다.

    SAM 분할·레이어

    SAM 모델 설정
    프롬프트 준비

    ① Grid 생성 → ② ML·수동점·box 추가 → ③ SAM 실행

    청록=Grid, 보라=ML, 초록/빨강=수동 +/−점. 점 위 오른쪽 클릭으로 제거할 수 있습니다.

    준비된 점 0개

    ML 추가점 제안 (실험)

    비지도 K-means로 밝기·국소 질감을 묶고 영역 내부의 점을 제안합니다. 층 이름을 인식하는 학습 모델은 아닙니다.

    자동 후보 필터

    Grid·ML·독립 양성점의 자동 후보에 적용합니다. 한 객체로 묶은 수동 후보는 별도로 보존합니다.

    후보 편집

    열 제목 클릭: 오름차순 ↔ 내림차순. Pixel은 마스크 면적(px)입니다.

    선택된 후보 없음

    레이어 관리

    레이어를 선택하면 그 레이어에 속한 마스크들을 함께 표시합니다. 레이어 삭제 시 후보 마스크는 유지됩니다.

    경계 보정·GT

    경계 보정과 GT 출력은 후속 구현 단계입니다.

    확정된 레이어 결과와 빈 영역·겹침 상태를 현재 화면에서 확인합니다.

    계측

    수평 정렬·기준점 및 계측 수치 산출은 후속 구현 단계입니다.

    대상 class/instance와 원본 좌표 변환 계약이 준비되어 있습니다. 이 페이지는 현재 수치를 생성하지 않습니다.

    설정·상태

    프로젝트는 서버의 projects/default에 자동 저장됩니다. 원본과 mask는 무손실 PNG입니다.

    CPU 추론 가능. ViT-H와 grid 32는 오래 걸릴 수 있습니다. 학습 notebook은 별도입니다.
    

    이미지별 일괄 적용·스케일 계산 결과
    행을 클릭하면 해당 이미지로 이동합니다. 실패한 계산은 —로 표시합니다.
    이미지상태바 길이(px)실제 길이px/nmnm/px스케일/글씨 ROI 수제외 px
    선택 후보 내부 재분할
    선택 후보 주변을 확대한 독립 편집창입니다. ROI와 양성·음성점 또는 box를 지정하세요. 결과는 부모 마스크 내부로 제한해 새 후보로 저장합니다.
