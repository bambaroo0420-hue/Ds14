# v2.3.0 누적 교체 패치 — 계측 표시 분리·통계·실행 이력

이 ZIP은 이전 겹침/빈틈 패치를 포함합니다. v2.3.0 또는 서버 setup r1/r2에 적용하며,
이전 겹침 패치를 이미 적용했어도 이 ZIP 하나만 병합 복사하면 됩니다.
SAM/OCR/패키지 재설치는 없습니다. 사용자 데이터·모델·.venv는 포함하지 않습니다.

## 설치

1. 작업 완료 후 run.py 서버를 Ctrl+C로 종료합니다.
2. 기존 소스와 프로젝트를 백업합니다.
3. ZIP의 `replacement` 안 `tem_analyzer`, `web` 폴더를 run.py가 있는 폴더 안으로 **병합 복사**합니다.
   같은 이름 파일만 덮어쓰며 폴더 전체를 삭제하지 마세요. 다른 버전/직접 수정본은 먼저 비교해야 합니다.
4. 기존 명령으로 서버를 재시작하고 브라우저 Ctrl+Shift+R을 누릅니다.

## 화면

- `4 회전·계측 → 계측선·끝점 보기`: 기본적으로 이미지에는 선·끝점만 표시합니다.
- 수치는 이미지 밖에 표시합니다. 결과 표의 행을 누르면 선택 위치의 길이·평균 대비 편차를 별도로 표시합니다.
- `선택 계측선의 수치를 이미지에도 표시`를 켜면 기존처럼 수치를 이미지에 겹쳐 표시할 수 있습니다.
  이 옵션은 선택 행에 적용되며 전체 선에 수치를 한꺼번에 겹치지는 않습니다.
- `계측 수치 · 통계 · 이력 저장`에 평균, 표준편차, 중앙값, 최소/최대, 범위, 유효/제외 개수를 표로 표시합니다.
- `회전 좌표 PNG 저장`은 현재 수치 표시 옵션을 반영합니다.

## 자동 저장과 다운로드

계측을 실행하면 **사용 중인 프로젝트 폴더** 아래에 실행별 결과를 저장합니다.

```
measurement_results/<image_id>/<run_id>.json
```

이미지·레이어·선택 마스크 집합·두께/CD·구간·스케일·좌표 변환·개별값·통계·저장 시각을 보존합니다.
다른 레이어/구간을 측정하거나 같은 조건으로 재측정해도 이전 실행 파일은 덮어쓰지 않습니다.
일괄 계측도 같은 저장 함수를 사용합니다. 화면은 기존처럼 가장 최근 결과를 표시합니다.

다운로드 버튼:

- `현재 이미지 계측 이력·통계 ZIP`
- `선택 이미지(없으면 전체) 계측 이력·통계 ZIP`

ZIP 내용:

| 파일 | 내용 |
|---|---|
| summary.csv | 이미지·레이어·실행·방향별 평균/표준편차/중앙값/최소/최대/범위/개수 |
| measurements.csv | 모든 개별 측정값·제외 상태·평균 대비 편차·원본/회전 좌표 끝점 |
| image_id/run_id.json | 해당 실행의 전체 설정·스케일·변환·결과 |

CSV는 UTF-8 BOM으로 저장해 Excel에서 한글을 읽도록 합니다. PNG는 별도 버튼으로 저장합니다.
기존 `회전·좌표 변환·계측 ZIP`은 기존 최신값/만료 차단 동작을 유지합니다.
새 이력 ZIP은 과거 결과도 내보내되 `stale_at_export=True`로 현재 입력과 맞지 않는 결과를 명시합니다.
과거 스케일로 계산된 결과를 새 스케일로 자동 재해석하지 않습니다.

## 통계 기준

- status=ok이고 유한한 length_nm만 통계에 포함합니다. 제외된 행은 CSV에 남깁니다.
- std_population_nm: 모집단 표준편차(ddof=0), UI 기본 표준편차.
- std_sample_nm: 표본 표준편차(ddof=1). 표본이 1개 이하면 비워 둡니다.
- deviation_from_mean_nm: 해당 실행 평균에 대한 개별 측정값의 차이.
- 통계는 서로 다른 이미지·레이어·실행을 합치지 않습니다. 같은 이미지 내 공간 표본이 독립이라는 가정이나 통계적 신뢰구간은 제공하지 않습니다.
- 미검수 마스크는 provisional 표시를 유지합니다. 자동 이상치 삭제는 없습니다.

## 보존·제한

- 실행 이력은 패치 이후 새로 측정한 것부터 남습니다. 이전에 덮어쓴 실행은 복구할 수 없습니다.
- 기존 프로젝트에 남아 있는 방향별 최신값도 내보내며, 실행 시각이 없으면 빈 값입니다.
- Undo/레이어 수정은 과거 실행 파일을 삭제하지 않습니다. 프로젝트를 백업할 때 measurement_results 폴더도 포함하세요.
- 이미지 삭제 시 보관된 결과 파일은 디스크에 남지만 현재 이미지 목록에서 제외됩니다. 이미지 복원 후 다시 접근할 수 있습니다.
- 이력은 자동 정리하지 않으므로 반복 실행이 많으면 디스크 사용량이 증가합니다.
- 스케일 제안 만료/UI 및 ROI 점 추가 자동 실행 문제는 이번 패치 범위가 아닙니다.
- 회사 이미지 정확도 검증은 별도입니다.

## 검증

Python 회귀 테스트 240개 및 기존 JavaScript 테스트 8개 통과.
별도 합성 프로젝트를 실제 브라우저에서 계측하고 글자 분리 화면·이력 ZIP 버튼을 실행했습니다.
합성 예제: 유효 44개, 제외 4개, 평균 25 nm, 모집단 표준편차 약 2.7716 nm,
최소 21 nm, 최대 29 nm. 수치 정합성은 저장된 JSON/CSV와 비교했습니다.
다운로드 ZIP, 테스트 로그, 실제 화면은 evidence에 포함합니다.
