이미지별 스케일 설정

자동 검출 후 바와 문자 및 nm/px를 확인·확정하세요. 수동으로는 바 양 끝과 실제 길이를 입력합니다. GT 생성 여부와 무관합니다.

바 길이: 미지정

OCR 설정

이미지 전체 OCR이 기본입니다. OCR 없이도 바 양 끝 + 실제 길이 입력으로 계산할 수 있습니다.

스케일 미확정

전체 이미지 일괄 적용·검수
기존 고정 위치 템플릿 일괄 적용

현재 템플릿과 드래그한 영역을 저장해 적용합니다. 위 실제 길이·단위를 모든 이미지에 공통 사용합니다. 바에 적힌 길이가 다른 이미지는 개별 수정하세요.

    자동 검출의 일괄 처리는 “5 일괄 처리 → 문자·바 검출”에서 실행합니다.

    원본은 보존됩니다. 적용한 영역은 분석용 이미지에서 주변 유효 픽셀로 채우고 결과에서 제외합니다. 적용 시 기존 후보의 검수 상태를 해제합니다.

    이미지상태바 길이(px)실제 길이px/nmnm/px스케일/글씨 ROI 수제외 px

    분홍색=분석 제외 영역, 주황색=스케일바. 검출 실패는 수동 스케일 저장 후 확정하세요. 템플릿 수정 후 다시 적용해야 분석에 반영됩니다.

    SAM 분할·레이어

    여러 이미지 분할은 5 일괄 처리에서 SAM만 선택하세요. 레이어 배정은 나중에 할 수 있습니다.

    다중 마스크 · 레이어 배정

    목록에서 Ctrl/Shift 선택 후 레이어에 드래그할 수 있습니다. 배정과 검수 확정은 별도입니다.

    목록 순서가 인접 층 순서입니다.

    기준 이미지로 레이어 대응 제안

    검수한 기준 마스크의 정규화 위치를 이용합니다. 물질 인식 모델이 아니며 결과 검수가 필요합니다.

    SAM 모델 설정

    학습 bundle은 기본 SAM 해시를 검증합니다. 학습 모델은 single-mask 경로를 사용하며 predicted IoU 필터는 적용하지 않습니다.

    SAM / 경계 전처리

    선택한 설정은 적용 버튼으로 저장합니다. 원본 파일·OCR·축척은 변경하지 않습니다. NLM은 큰 이미지에서 시간이 걸릴 수 있습니다.

    프롬프트 준비

    ① Grid 생성 → ② ML·수동점·box 추가 → ③ SAM 실행

    청록=Grid, 보라=ML, 초록/빨강=수동 +/−점. 점 위 오른쪽 클릭으로 제거할 수 있습니다.

    준비된 점 0개

    ML·에지 추가점 제안 (실험)

    K-means는 비지도 군집, 나머지는 영상처리 방식입니다. 물질 분류 모델이 아닙니다. 에지 위가 아닌 내부 영역에 독립 양성점을 제안합니다.

    층 횡단 프로파일 설정

    반대 부호의 밝기 경계 사이 중점을 제안합니다. 에지 최소 거리의 2배보다 좁은 구간은 제외됩니다. 얇은 층은 거리·평활을 줄여 미리보기로 확인하세요. 각 점은 독립 SAM 양성점이며 물질별 묶음/GT가 아닙니다.

    분석은 선택한 긴 변 최대 512/1024px에서 수행합니다 (K-means 내부는 최대256px). 필터 강도는 분석 픽셀 기준, 점 좌표·거리는 원본 기준입니다. 원본 파일 및 SAM 입력은 바뀌지 않습니다. SAM 입력용은 위 전처리에서 별도로 저장하세요.

    자동 후보 필터

    Grid·ML·독립 양성점의 자동 후보에 적용합니다. 한 객체로 묶은 수동 후보는 별도로 보존합니다.

    후보 편집

    열 제목 클릭: 오름차순 ↔ 내림차순. Pixel은 마스크 면적(px)입니다.

    선택된 후보 없음

    레이어 관리

    레이어를 선택하면 그 레이어에 속한 마스크들을 함께 표시합니다. 레이어 삭제 시 후보 마스크는 유지됩니다.

    공유 경계 보정·GT

    2번 화면에서 레이어에 지정한 후보 A를 선택하세요. 인접 후보 B 또는 명시적 배경과의 공통 경계를 보정합니다.

    실제 적용 마스크(초록)는 보호·공유 경계 제약까지 반영한 결과입니다.

    GT 상태·보호 영역

    브러시 추가 도구로 영역을 그린 뒤 상태를 지정하세요. 미지정은 배경으로 간주하지 않습니다.

    semantic·labels·lab_mask·center·edge·valid와 원본·메타데이터를 출력합니다. 학습 시 valid 마스크를 반드시 함께 사용하세요.

    후보 비교 평가
    동일 이미지의 사용자 검수 후보를 기준으로 비교합니다. 독립된 테스트셋 성능을 의미하지 않습니다.

    측정 구간
    분리 객체·구멍은 별도 구간으로 측정합니다. 제외·충돌 영역은 무효로 표시합니다.
    위치 px구간길이 nm상태
    

    여러 이미지 일괄 처리
    자동 결과는 제안 상태로 남습니다. 검수 후 다음 단계를 실행하세요.
    

    Grid/ML 방식은 2번 화면의 설정으로 이미지마다 점을 새로 계산합니다. 재사용 방식은 아래에서 이미지별로 준비·검수한 점과 box를 실행합니다. SAM 입력 전처리는 각 이미지에 저장된 설정을 사용합니다.
    

    설정은 1~4번 화면의 값을 사용합니다. 회전 제안 후 일괄 확정하고 계측을 별도로 실행하세요.
    추론 중 취소 요청은 현재 단계가 끝난 뒤 반영됩니다. 완료 결과는 보존됩니다.
    

    설정·상태
    프로젝트는 서버의 projects/default에 자동 저장됩니다. 원본과 mask는 무손실 PNG입니다.
    CPU 추론 가능. ViT-H와 grid 32는 오래 걸릴 수 있습니다. 학습 notebook은 별도입니다.
    

    이미지별 일괄 적용·스케일 계산 결과
    행을 클릭하면 해당 이미지로 이동합니다. 실패한 계산은 —로 표시합니다.
    이미지상태바 길이(px)실제 길이px/nmnm/px스케일/글씨 ROI 수제외 px
    선택 후보 내부 재분할
    선택 후보 주변을 확대한 독립 편집창입니다. ROI와 양성·음성점 또는 box를 지정하세요. 결과는 부모 마스크 내부로 제한합니다. 주황색 미리보기를 확인한 뒤 저장해야 새 후보가 생성됩니다.
