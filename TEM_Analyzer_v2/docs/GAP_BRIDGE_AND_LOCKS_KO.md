# 레이어 잠금과 두 층 사이 빈틈 보정 — 2026-10-01 작업본

v2.2.9 기반의 로컬 작업본에 추가한 기능입니다. 이번 변경만으로 이전 UI 개편 요구 전체가 완료된 것은 아닙니다. Desktop 설치본, 공개 GitHub, ZIP에는 아직 반영하지 않았습니다.

## 질문에 대한 답

“작은 틈”은 재료의 물리적 크기를 뜻하지 않습니다. 기존 자동 보정에서 탐색/확장을 허용한 원본 픽셀 폭입니다. 동일한 20px도 축척에 따라 다른 nm이므로 물리적 임계값으로 해석하면 안 됩니다.

사용자가 제안한 **두 마스크 사이의 빈 영역에서 Gradient가 강하고 연속적인 공통 경계를 찾고, 양쪽 마스크를 그 경계까지 확장**하는 기능을 별도로 구현했습니다. A와 B가 각자 가장 큰 Gradient로 독립 이동하는 방식은 서로 다른 피크를 선택하여 새 틈/겹침을 만들 수 있습니다. 하나의 공유 경로를 찾고 양측에 픽셀을 나누어 배정합니다.

| 검수 결과 | 처리 |
|---|---|
| 두 층 사이의 SAM 분할 누락 | 두 레이어를 선택하고 탐색 폭/ROI를 조절 → 제안 확인 → 적용 |
| 실제 제3층 | 별도 레이어 C를 만들고 SAM/브러시로 지정. A–C, C–B 경계로 각각 보정 |
| 실제 공극/배경 | 배경 등 적절한 의미를 직접 지정. A/B로 강제로 흡수하지 않음 |
| 판단 불가 | 미지정/불확실로 남김. 유효한 semantic 학습 정답으로 취급하지 않음 |
| 한 마스크 내부의 구멍 | 이번 기능은 보존. 분할 누락으로 확인한 구멍은 대상 후보를 선택해 브러시 추가로 수정 |

내부 구멍과 층 사이 틈은 다른 문제입니다. 내부 구멍에는 두 층이 공유할 경계가 없을 수 있고, 실제 공극/다른 재료일 수도 있습니다. **자동 내부 구멍 채우기 기능은 이번에 추가하지 않았습니다.** 다른 레이어를 잠근 뒤 브러시로 확인된 영역만 채울 수 있습니다.

## 화면 사용법

### 브러시 레이어 잠금

1. 캔버스 위 `브러시 · 레이어별 잠금 (프로젝트 전체)`에서 수정하지 않을 레이어를 잠급니다.
2. `2 SAM·레이어 → 후보 편집`에서 수정할 후보를 선택합니다. 상단에 후보 번호·소속 레이어·잠금 상태가 표시됩니다.
3. `입력 방식 → 브러시 추가/삭제`로 그린 뒤 `브러시를 새 후보로 저장`을 누릅니다.
4. 결과 확인 후 기존 레이어 확정/부모 교체 절차를 사용합니다. 브러시 후보 생성과 레이어에 적용은 서로 다른 작업입니다.

잠긴 대상은 브러시 저장을 차단합니다. 다른 레이어가 잠겨 있으면 그 픽셀은 붓이 지나가도 바꾸지 않습니다. 보호 영역도 보존합니다. 잠금은 현재 이미지만이 아니라 프로젝트 전체의 해당 레이어에 적용됩니다. 미리보기 후 잠금/보호가 변경되면 서버에서도 재검사합니다. 중간 브러시 후보를 반복 생성해도 원래 편집 대상의 잠금을 확인합니다.

기존 코드에서 브러시 확정 시 다른 잠긴 층 전체가 영구 수동 보호로 저장될 수 있던 문제를 수정했습니다. 이제 레이어 잠금과 수동 보호를 별도로 저장합니다. 실제 수동 보정 보호는 유지되므로 잠금 해제만으로 수동 보호가 지워지지는 않습니다.

### 새 빈틈 보정

1. `3 경계·GT → 두 레이어 사이 빈틈 · Gradient/DP 연결`을 펼칩니다.
2. A/B 레이어를 선택합니다. 목록 순서만으로 이웃층을 추정하지 않습니다. 선택한 층은 잠겨 있으면 안 됩니다.
3. `최대 빈틈 폭`을 지정합니다. 기본 30px, 지원 범위 1~200px. 이는 **원본 이미지의 탐색 축 방향 빈 픽셀 수**이며, 곡선 법선 방향 두께나 nm 기준이 아닙니다.
4. 특정 구간만 보려면 `입력 방식 → 경계/회전 ROI 드래그`로 그린 뒤 `그린 ROI 내부만`을 선택합니다.
5. `빈틈 경계 자동 제안 · 크게 보기`를 누릅니다.
6. 흰색/주황의 기존 경계, 청록 공통 경계, 분홍 신규 편입 픽셀, 실제 Gradient 프로파일 및 건너뛴 사유를 확인합니다.
7. 두 층의 분할 누락임을 확인하는 체크박스를 선택하고 적용합니다. 영상 로드 실패, 변경 없음, 입력 변경 상태에서는 적용을 차단합니다.
8. 적용 완료 문구와 새 후보 번호를 확인합니다. `GT 상태 표시`로 레이어 전체를 볼 수 있습니다. 결과는 **미검수 후보**이며 GT 확정은 별도입니다. Undo 가능합니다.

`복수 Gradient 피크도 제안`은 기본 꺼짐입니다. 제3층 의심 구간을 자동 검수 완료로 바꾸는 옵션이 아닙니다. 사용자가 실영상을 보고 제3층이 아니라고 판단할 수 있을 때만 검토용으로 켜야 합니다.

## 알고리즘과 안전 기준

현재 구현은 위/아래 또는 좌/우로 구별되는 층에 적합합니다. 각 스캔에서 A/B 각각 하나의 연속 구간만 있는 경우를 대상으로 합니다. 완만하게 기울거나 휜 경계도 추적하지만 임의 외곽 법선 탐색, T자 접합, 복잡한 다중 교차를 일반적으로 해결하지 않습니다.

1. 레이어 활성 마스크를 합집합으로 만들고, 두 레이어 사이의 양의 빈 구간을 찾습니다. 이미 겹치는 선택 레이어는 먼저 겹침 해결이 필요합니다.
2. 원본 좌표계에서 경계용 전처리 영상의 밝기를 0~1로 정규화하고 Gaussian sigma=1 후 탐색 방향의 인접 밝기 차이를 계산합니다.
3. 비용은 큰 Gradient 선호 + 약한 중앙 위치 선호 + 이웃 스캔 간 이동 패널티입니다. DP로 연속된 하나의 경로를 선택합니다. 기본 최소 Gradient 0.015, 연속성 0.12, 점간 최대 이동 4px입니다.
4. 경로 한쪽 빈 픽셀은 A, 반대쪽은 B로 배정합니다. 기존 마스크 내부 픽셀은 삭제하지 않습니다. 따라서 경계가 이미 마스크 내부로 잘못 들어간 경우는 기존 경계 보정/브러시가 별도로 필요합니다.
5. 약한 신호, 복수 피크, 큰 틈, 짧은 연속 구간, 경로 단절, 보호/제외/제3 레이어, 객체 수/구멍 수 변화는 건너뜁니다. 내부 구멍이 있는 스캔은 보수적으로 제외되어 그 위아래 틈도 일부 남을 수 있습니다.

복수 피크 검출은 휴리스틱입니다. 매우 얇은 제3층이나 약한 경계를 완벽히 감지하지 못합니다. 가장 큰 Gradient가 원하는 물질 경계라는 보장도 없습니다. **자동화 범위는 경계 제안 계산과 픽셀 배정이며, 재료 의미 판단은 검수가 필요합니다.**

이번 새 방법은 단일 이미지의 명시적 두 레이어 선택 UI입니다. 기존 일괄 경계 작업은 이전 방법을 계속 사용하며, 새 방법을 자동으로 일괄 실행하도록 연결하지 않았습니다. 내부 구멍 자동 채움·모든 픽셀 자동 semantic 완성도 미구현입니다. SAM 모델/decoder/recipe 형식은 변경하지 않았고 추가 패키지도 필요하지 않습니다.
