2026-09-30. 요구 정리 단계이며 앱 코드는 변경하지 않았습니다.

| 영역 | 수정사항 |
|---|---|
| 공통 | 이미지·레이어 선택 상단 고정, 현재 대상·도구·잠금·검수 상태 표시 |
| 배정 패널 | 이동·도킹·위치 고정, 가까운 배정 버튼, 드롭 목적지 강조 |

| 다중 선택 | 선택한 마스크 모두 캔버스에 동시 표시, 목록과 동기화 |
| Manual | Manual 1/2… 그룹별 점·box·잠금·실행·결과 추적 |
| 레시피 | ROI 재분할 점·box·좌표·부모·설정 저장, 저장 버튼 차별화 |
| GT | 전체 레이어와 편집 A/B 표시, 겹침·틈·배경·미지정 구분 |

| Gradient+DP | 탐색 띠·법선·gradient·DP 경로·고정점·실제 적용선 표시 |

| 계측 | 측정 대상·구간·방향·끝점·치수선, 표와 영상 연동, 제외 사유 |
| 발표 | 레이어/경계/gradient/회전/계측 그림과 CSV·JSON 출력 |
| 매뉴얼 | 버튼 목적·선행조건·조작·변경 대상·확인·Undo를 MD로 설명 |

색은 표시용이며 Semantic GT는 클래스 ID와 유효성 정보입니다. 미분할은 자동 배경이 아니라 Unknown입니다. 다른 클래스는 합쳐 없애지 않고 공유 경계로 나눕니다. 회전 기준과 측정 대상은 구분하며 GT 없이도 계측할 수 있어야 합니다.

순서: 공통 선택/시각화 → GT 편집 → 회전·계측 → Manual/레시피 → 발표 출력·매뉴얼. 19.jpg 파생 영상과 생성 정답 마스크로 실제 GUI·수치·잠금·좌표·저장 복원을 검증합니다.

## 추가 검토 — 독립 ROI와 일괄 recipe

- 독립 ROI 실행 실패를 실제 환경에서 재현하고, 수동 객체/ROI 자동 후보 모드와 모드별 파라미터를 분리합니다. 기존 후보 1/2/3 선택은 대안 비교이며 여러 객체 생성이 아닙니다.
- 일괄 재사용은 저장한 수동점·box와 Grid/ML 점 좌표를 적용할 수 있지만, 일반 Grid+ML 경로에는 recipe 수동점이 포함되지 않습니다. ML 좌표 재사용과 대상별 ML 재생성을 별도 정책으로 만들고 이미지별 적용 내역을 표시합니다.
