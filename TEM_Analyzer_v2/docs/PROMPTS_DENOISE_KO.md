# 선택형 추가점·노이즈 제거 사용법

## 현재 지원 범위

`2 SAM·레이어 → 프롬프트 준비 → ML·에지 추가점 제안`에서 선택합니다.

- K-means: 밝기/국소 질감의 비지도 군집 중심. 물질 분류 모델 아님.
- Canny / Sobel / Scharr: 경계 검출 후 경계 사이 내부의 거리변환 최대점.
- 혼합: K-means 후보 중 Canny 경계에서 떨어진 점 + 내부 최대점.
- 프롬프트 분석용 필터: 없음 / Gaussian / Median / Bilateral / Non-local Means.

`필터·점 미리보기`는 SAM을 실행하거나 점을 추가하지 않습니다. `제안점을 프롬프트에 추가`로 보라색 점을 추가하고 위치를 검토한 뒤 `준비한 프롬프트로 SAM 실행`을 누릅니다. 기존 점 간격/제외 영역 때문에 최대 수보다 적게 나올 수 있습니다. `추가점만 지우기`는 Grid·수동점·box를 보존합니다.

프롬프트 분석은 긴 변 최대 512px이며 K-means 내부 군집 분석은 최대 256px입니다. 필터 sigma/크기는 분석 픽셀 기준, 반환 점과 최소 거리/에지 이격은 원본 픽셀 기준입니다. 작은 층이 축소되거나 노이즈 제거로 사라질 수 있습니다. 미리보기의 주황색은 검출 경계, 보라색은 새 제안점, 짙은 붉은색은 제외 영역입니다.

프롬프트 분석용 필터는 **SAM 입력을 바꾸지 않습니다.** SAM/경계 입력도 바꾸려면 별도 `SAM / 경계 전처리`에서 대상·사용·방법을 선택한 후 `현재 이미지에 적용`으로 저장하세요. Gaussian/Bilateral에 Median/NLM이 추가됐습니다. 원본 파일·OCR·스케일은 변경하지 않습니다. NLM은 큰 입력에서 오래 걸릴 수 있습니다.

## 여러 이미지를 먼저 분할

1. `1 이미지·스케일`에서 이미지를 로드하고 필요시 Ctrl/Shift 다중 선택.
2. `2 SAM·레이어`에서 모델 로드 및 추가점 설정. 화면 안의 `분할할 이미지` 목록으로 현재 이미지 변경 가능.
3. `5 일괄 처리`에서 전체/선택 대상을 고르고 **SAM 마스크 생성만** 체크.
4. `SAM 일괄 프롬프트`: Grid만 / Grid+추가점 / 추가점만.
5. 완료 후 `2 SAM·레이어`에서 이미지를 바꾸며 마스크를 편집·레이어 배정.

현재 일괄 기능은 같은 알고리즘 설정으로 **각 이미지에서 점을 새로 계산**합니다. 기준 이미지의 수동 +/−점·box를 다른 영상에 전송하는 기능은 아직 없습니다. 위치가 다른 영상에서는 단순 좌표 복사 대신 정합/전송 미리보기가 필요합니다. 이미지가 바뀌면 SAM 인코딩도 필요하므로 프롬프트 재사용만으로 추론이 생략되지는 않습니다.

일괄 SAM은 각 이미지에 저장된 SAM 전처리를 사용합니다. 현재 화면에서 필터를 고르기만 하거나 한 이미지에 저장한 것이 다른 모든 이미지에 자동 적용되는 것은 아닙니다.

## 의존성·수정 위치

새 기능은 `requirements.txt`의 `opencv-python-headless>=4.8,<5`를 사용합니다. 기존 환경에는 OCR 설치 과정으로 이미 있을 수 있습니다. 필요한 경우 해당 가상환경에서 한 번만 `python -m pip install -r requirements.txt`를 수행합니다. 매 실행 설치하지 않습니다.

- `tem_analyzer/feature_prompts.py`: 검증된 설정, 경계/혼합 제안, 미리보기. 새 방법은 이곳에 추가.
- `tem_analyzer/prompts.py`: 기존 Grid/K-means 계산.
- `tem_analyzer/preprocessing.py`: SAM/경계 공통 비파괴 필터, 필터 영향 반경.
- `api.py`의 `/api/prompts/ml`: 호환 경로. method 생략 시 K-means.
- `routes/workflow.py`: 이미지별 배치 재생성.
- `web/app.js`, `web/modules/batch.js`: 단일/일괄 UI 연결.
- `tests/test_feature_prompts.py`, `tools/review_public_images.py`: 회귀/공개 이미지 검증.

예제 설정 하나를 모든 회사 이미지의 최적 설정으로 간주하지 마세요. 실제 검토 결과와 한계는 [공개 이미지 검토](PUBLIC_IMAGE_REVIEW_KO.md)를 참고하세요.
