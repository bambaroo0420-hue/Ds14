## 문자 제거는 무엇을 의미하는가

현재 코드는 원본을 크롭하거나 복원하지 않습니다. OCR 박스를 분석 입력에서 주변 픽셀로 채우고, 그 위치를 결과 마스크/계측의 유효 영역에서 제외합니다. 이번 이미지에서는 전체 약 5.58%가 자동 제외되었습니다.

실제 분석 입력을 보면 큰 `TaOx~7nm` 박스 위치에 줄무늬성 채움이 생겼습니다. `TiOxNy~3nm`, 화살표, 노란 선은 남았습니다. 따라서 **“글자가 모두 지워졌고 조직이 정확히 복구되었다”는 판정은 할 수 없습니다.** 채움으로 생긴 가짜 경계가 SAM 결과에도 영향을 줄 수 있습니다.

OCR 제안 8개 중 3개는 미확정 바 후보입니다. 실제 5nm 바 외에 문자 획에 해당하는 짧은 후보도 포함되었습니다. 이 후보들을 무조건 적용하면 안 됩니다.

## 왜 5nm 계산이 실패했는가

실제 바는 검출됐고 OCR도 `5 nm`를 읽었습니다. 그러나 OCR의 글자 박스가 바까지 포함하는 큰 범위로 반환되어, 기존 바/문자 겹침 제한에 걸렸습니다. 7nm와 3nm를 스케일로 오선택하지는 않았지만, 올바른 5nm도 자동 확정 후보로 연결하지 못했습니다.

검출된 70.0006px 바가 맞다고 사람이 확인한다면 계산은 `5 / 70.0006 ≈ 0.071428 nm/px`입니다. 이는 **수동 검토를 전제로 한 계산 예**이며 현재 자동 저장/확정된 축척이 아닙니다. 문자와 바를 한 OCR 박스가 감싸는 사례를 처리하는 보완이 필요합니다.

## 회전 실험

경계 보정이나 GT 생성 없이 실제 SAM 후보를 Layer 1에 배정하고 회전을 계산했습니다. W를 선택하기 위한 양성 2점·음성 1점은 사람이 지정한 보조 프롬프트입니다. 즉 물질명 자동 분류 실험이 아닙니다.

| 방식 | 보정각 | 직선 잔차(px) | 해석 |
|---|---:|---:|---|
| 자동 기본, 위쪽 경계 | 0.0000° | 0.0000 | 상단 영상 테두리를 잡음. 작은 잔차가 정답 보장은 아님 |
| 마스크 아래쪽 전체 | +5.3926° | 13.0917 | 잘못 분할된 마스크의 경계. 큰 잔차 |
| 마스크 아래쪽 ROI | +2.0617° | 5.3001 | ROI만으로 잘못된 마스크를 해결하지 못함 |
| 원본 입력 + 더 많은 보조 SAM 점 | 계산 불가 | — | 지정 ROI에 유효 경계점 부족. 성공 사례로 바꾸어 기록하지 않음 |
| 수동 기준점 (80,357), (300,140) | +44.6067° | 두 점 직선이므로 사실상 0 | 수평에 가깝게 회전. 두 점 적합 잔차는 정확도 지표가 아님 |

각도는 이미지 좌표계 기준 양수가 시계 방향입니다. 수동 두 점 결과에서 노란 표시선은 거의 수평이 됩니다. 다만 노란 선은 논문 작성자의 주석이며 실제 물질 경계의 독립 GT가 아닙니다. 약 45°라는 사용자 설명과 시각적으로 부합할 뿐, 물리적 기준의 각도 오차를 검증한 것은 아닙니다.

원본→회전 동차 변환과 역행렬이 저장되어 회전 후 계측선의 양 끝을 원본 좌표로 되돌릴 수 있습니다. 회전만 하므로 원래 nm/pixel 값 자체를 변경하지 않습니다. 이 사례의 축척과 마스크가 확정되지 않았으므로 최종 두께/CD 값은 만들지 않았습니다.

## 필요한 개선

1. 큰 OCR 박스와 재료 구조 오검출을 거부하고, 5nm 문자/바가 겹친 박스 내부를 재분석.
2. 잘린 화학식·작은 문자에 대한 다중 스케일 OCR 및 박스 수동 수정.
3. 화살표·유색 표시선·영상 테두리의 별도 주석 마스크. 문자 채움과 실제 경계 보존을 구분.
4. 마스크 영상 테두리 접촉 구간을 회전 기준에서 제외. 경계 방향 투표/RANSAC과 마스크 기반 방향의 일치 확인.
5. 필요하면 거친 방향 추정 → 좌표 변환을 유지한 임시 정렬 → SAM 프롬프트/분할 → 원본/최종 회전 공간으로 환산하는 경로를 비교. 이 방법은 아직 제품 구현/검증하지 않음.
6. 수동 두 점/ROI 대안은 유지하되 자동 결과와 수동 개입 이력을 명시.
