# v2.2.3 — 프롬프트 일괄 재사용과 정합 실패 개선

2026-09-30 KST. 5시간 반복 개선 중 4차 보고서이며 최종 회사 정확도 검수가 아닙니다.

## 사용자 의도와 구현

여러 영상을 먼저 분할하고 레이어 배정은 나중에 하는 흐름에, **저장한 점·box의 일괄 재사용**을 연결했습니다. Grid / feature / Grid+feature는 그대로 별도 선택입니다. Canny·Sobel·프로파일은 학습된 물질 분류기가 아니라 추가점 제안입니다.

1. 2번 SAM 화면에서 기준 영상의 Grid/추가점/수동점/box를 preset으로 저장합니다.
2. 이미지 목록에서 Ctrl/Shift로 대상을 선택합니다. 5번 화면에서 preset과 좌표 변환을 고르고 **준비만 실행**합니다.
3. 표의 이미지별 `점·box 보기`를 열고 위치를 확인합니다. 미리보기 영상이 로드돼야 확정 대상에 넣을 수 있습니다.
4. 미리본 행을 선택해 프롬프트 검토를 확정합니다. 이는 물질·마스크·GT 확정이 아닙니다.
5. SAM 일괄 프롬프트를 `저장·검수한 재사용 프롬프트`로 고르고 **SAM만** 실행합니다. 기존 후보를 보존하고 미배정 후보를 추가합니다.
6. 이후 필요한 후보만 선택 scope에 저장하거나 레이어에 배정합니다. 미선택 영역은 계속 unknown입니다.

자동점은 독립 후보 생성, object 수동점의 +/−와 box는 한 객체 조건으로 실행합니다. independent 수동 양성점은 각각 독립 후보 경로입니다. 두 경로를 섞으면 중복/겹친 후보가 생길 수 있으며 자동 semantic GT로 간주하지 않습니다.

## 실패 방지

- 준비와 SAM을 같은 작업으로 실행할 수 없습니다. 준비는 추론하지 않습니다.
- 새 준비를 시작하면 이전 draft의 검토를 먼저 만료시킵니다. 실패/취소 후 옛 점이나 Grid로 몰래 대체하지 않습니다.
- 원본 preset, 기준·대상 영상, 기준·대상 제외 영역, 대상 SAM 전처리가 바뀌면 재준비·검수가 필요합니다.
- 미리보기의 서명과 검토 요청이 다르면 차단합니다. 여러 행의 확정은 모두 유효할 때만 반영합니다.
- 대상 하나의 실패는 다른 이미지의 성공 결과를 삭제하지 않습니다. 기존 마스크는 불변 파일로 유지합니다.
- 이미지 삭제 시 재사용 draft도 휴지통 메타데이터에 포함하며 이미지와 함께 복원합니다. preset의 기준 이미지가 없으면 재사용은 거절됩니다.

## 실제 SAM 비교

원본 19.jpg에서 만든 기존 1-cell/3-cell crop·회전 프로젝트를 **읽기만** 하고 새 프로젝트에서 실행했습니다. 3-cell은 같은 셀을 반복한 합성 montage이며 독립 촬영 영상이 아닙니다. 표의 IoU는 기존 SAM 마스크와 새 후보 중 가장 잘 맞는 후보의 비교입니다. **전문가 GT 정확도도, 자동 후보 선택 정답률도 아닙니다.**

| 방법 | 3-cell +7° 양끝 마스크 IoU | 3-cell −8° 양끝 마스크 IoU | 실제 결과 |
|---|---|---|---|
| 영상 크기 비율 | 0.9315 / **0.0990** | 0.9872 / 0.9936 | +7° 오른쪽 점이 셀 위 배경으로 이동해 큰 배경 후보 생성 |
| 기존 ECC | 차단 | 차단 | 상관계수 0.731 / 0.708, 기준 0.85 미달; 자동 대체 없음 |
| 중앙 50% + 양쪽 제외 ECC 시제품 | 0.9523 / 0.9923 | 0.9727 / 0.9944 | 양끝 셀 내부 점·후보 확인; 가운데 셀은 미선택 |

기존 ECC 1-cell +7°는 상관계수 0.8758, IoU 0.9938로 작동했습니다. 양쪽 제외 방식은 같은 경우 상관계수 0.99994, IoU 0.99335였습니다. 상관계수 증가가 물질 정확도 증가를 의미하지 않습니다.

실제 SAM 실행은 기존 방식 비교 8회(5 normalized + 3 ECC), 양쪽 제외 시제품 5회, 최종 coarse-to-fine 방식 GUI 3회로 **총 16회**입니다. 비교 스크립트의 SAM job 시간 합계는 170.656 + 98.738초, GUI 두 장 job은 28.867초, 검수 후 재시도 한 장은 14.576초였습니다. 로딩·정합·사람 검수 시간을 모두 포함한 처리량 비교가 아닙니다.

## 최종 실험적 정합 방식

OpenCV의 `findTransformECCWithMask`로 기준·대상 양쪽 유효 영역을 사용합니다. 서로 다른 footer·문자·패딩이 정합 점수에 영향을 주는 문제를 줄이기 위해 중앙 가로/세로 50%를 사용합니다. 축척 변화 없는 Euclidean 회전·이동만 다룹니다.

128 px급 coarse → 최대 512 px fine, −10/0/+10° 초기값을 사용합니다. 최종 상관계수 0.85 미만, 회전 ±20° 밖, 유효 면적/질감 부족, 비슷한 점수의 서로 다른 위치는 거절합니다. 중앙에 관심 구조가 없는 영상에는 맞지 않는 **선택형 실험 모드**이며 기존 ECC 기본값을 강제로 바꾸지 않았습니다.

저해상도 단계 없이 합성 미세 질감 영상에 9 px 이동을 더했을 때 정합이 실패했습니다. coarse-to-fine 추가 후 서로 다른 제외 박스와 −12/0/+7/+15° 및 이동(9,−5 px)의 4대조군이 0.4 px 이내 기준을 통과했습니다. 무질감·관계없는 잡음·거의 전체 제외는 거절했습니다.

최종 코드의 알려진 19 생성 좌표 5장, 각 3 control point 비교:

| 영상 | 최대 control point 위치 차이(px) |
|---|---:|
| 1-cell 0° | 0.000004 |
| 1-cell +7° | 0.023294 |
| 3-cell 0° | 0.000015 |
| 3-cell +7° | 0.096926 |
| 3-cell −8° | 0.079726 |

이는 생성 변환에 대한 좌표 검증이며 TEM 물질 경계 오차가 아닙니다. 반복 셀의 한 주기 오대응, 배율 차이, 휘어짐, 큰 시야 차이는 여전히 별도 문제입니다. 높은 점수만으로 재사용을 무검수 확정하지 않습니다.

## 장단점과 남은 일

장점은 분할 우선 일괄 처리, 기준 점/수동 box 재사용, 실패 격리, 원본 보존, 영상별 검토 이력입니다. 한 영상당 preset 하나를 선택하는 현재 방식은 물질별 여러 preset 동시 운용보다 단순하지만 반복 설정이 필요합니다. 200장씩 준비할 수 있으나 모든 점의 물질 일치 검수는 남습니다.

프롬프트만 맞아도 SAM 경계가 완벽하지 않습니다. 얇은 층·저대비·화살표·색 선·OCR 미검출의 경계 오류, 첨부 약45° 영상의 변형별 자동 수평 불안정은 이 변경으로 해결됐다고 주장하지 않습니다. 회사 영상과 전문가 GT를 확보하면 물질별 IoU/경계 거리와 두께/CD 오차를 별도 평가해야 합니다.

추가 우선순위: 잘못된 재사용 점을 해당 이미지에서 직접 편집 후 재검수하는 표 연결, 대응 신뢰도의 국소 검증, 관심 mask의 ROI 확대 SAM 비교, 회사 촬영 배율별 recipe 관리. 새 모델 도입은 라이선스·오프라인 설치·체크포인트 검증을 먼저 해야 합니다.
