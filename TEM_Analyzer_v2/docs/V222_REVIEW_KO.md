# v2.2.2 — 얇은 층 추가점·방향 반례·선택 집합 표시

검토일: 2026-09-30 KST. 5시간 반복 작업의 3차 중간 결과이며 최종 현장 정확도 인증이 아닙니다.

## 결론

프로파일 추가점은 테스트한 얇은 합성 층에 도움이 되었지만, 공개 TEM의 물질 경계 정답을 자동으로 찾는 모델은 아닙니다. Grid/추가점/혼합과 비교하여 사용자가 선택할 실험 옵션으로 추가했습니다. 회전 자동화는 첨부 영상의 변형에서 여전히 실패할 수 있으며, 낮은 신뢰도 경고를 제거하지 않았습니다.

필요한 mask만 선택하여 레이어 없이 부분 GT·회전·계측하는 기존 v2.2 흐름은 유지합니다. 선택 집합 전체 큰 미리보기로 현재 후보 한 개와 실제 분석 범위를 구분합니다.

## 실제 SAM 비교

`tools/compare_profile_prompts.py`, 로컬 `test-output/profile-v222/results.json`.

- 생성 GT: 384×256, 두께4/6/10/5px인 4개 밝고 어두운 띠, 0/+25/−45°, Gaussian noise σ5. 서로 독립인 현장 시편이 아니라 동일 패턴의 변형입니다.
- 공개3장: 기존 모음140(Cu/Ru/MgO/Ta/Si),158(MTJ), 신규 수집 hafnia h. 원본/출처/해시는 `public-review/cases.json`과 이전 공개 검토 문서에 보존되어 있습니다. 추가 다운로드 없이 기존 확보본을 재사용했습니다.
- ViT-B CPU 실제 모델, native multi-mask, pred IoU .5 / stability .7 / NMS .8. 모든 실행에서 encoder 초기화, 원본 SAM 입력 동일. 공개 영상의 자동 OCR 제외 마스크도 각 전략에 동일 적용. 전문가가 검수한 제외 영역은 아닙니다.
- nominal16점: Grid4×4, Sobel최대16, Profile최대16, Grid3×3 + Profile로16까지. 제외 영역 때문에 공개 Grid는 15/15/11점입니다.
- Median3, 점 간격8px, 에지 최소 거리1px. Sobel분석512, Profile분석1024, profile 최대폭40px. 따라서 **설정 레시피 비교이지 해상도까지 동일한 알고리즘 단독 비교는 아닙니다.**
- 실제 추론24회, 기록 시간 합376.95s. 일부 다른 실험이 병행되었으므로 속도 순위 비교는 하지 않습니다. 모델/OCR 로드 시간은 이 합에서 제외됩니다.

| 전략 | 합성12개 띠에 점이 들어간 수 | 띠별 최고 IoU의 평균 |
|---|---:|---:|
| Grid | 2/12 | 0.2688 |
| Sobel | 0/12 | 0.0148 |
| Profile | 12/12 | 0.9188 |
| Grid+Profile | 7/12 | 0.4864 |

**최고 IoU는 생성한 모든 후보 중 GT에 가장 잘 맞는 후보를 사후 선택한 oracle 값입니다.** 자동 선택 정답률, precision, 물질 분류, 계측 정확도와 다릅니다. SAM은 점을 직접 찍지 않은 띠도 후보로 만들 수 있습니다. 불필요한 추가 후보의 벌점도 이 수치에 포함되지 않습니다. Grid+Profile이 항상 더 좋지 않은 것은 총16점 예산 중 프로파일에 남는 점이 적기 때문입니다.

| 입력 | Grid 후보 | Sobel 후보 | Profile 후보 | Grid+Profile 후보 |
|---|---:|---:|---:|---:|
| 합성0° | 5 | 6 | 6 | 6 |
| 합성+25° | 6 | 3 | 10 | 9 |
| 합성−45° | 5 | 3 | 18 | 9 |
| 공개140 | 5 | 6 | 9 | 13 |
| 공개158 | 5 | 2 | 13 | 13 |
| 공개hafnia h | 4 | 5 | 5 | 11 |

공개 결과에는 전문가 GT가 없습니다. 140의 여러 띠 후보는 확인했지만, 얇은 층 경계의 정량 개선은 판정하지 않았습니다. hafnia h는 격자/텍스트가 조밀하고 프로파일 점도 불필요한 영역에 놓입니다. 후보 수 증가는 정확도 향상으로 해석하지 않습니다. 필터를 강하게 하면 얇은 층 자체가 사라질 수 있습니다.

## 회전 반례와 안전한 변경

`tools/validate_real_orientation.py`는 원본 파일/프로젝트를 읽기만 합니다. 이미지와 OCR 제외 마스크를 같은 좌표 변환으로 회전시키고 확장 패딩을 제외합니다. 0/−60/−30/−15/+15/+30/+60°의 추가 회전, 공개43/140/143와 첨부45° 총4입력×7각도입니다.

이 검사는 **추가 회전에 대한 일관성(equivariance)**이며, 처음 영상의 기준 각도가 정확하다는 증거가 아닙니다. 실제 물질 경계 GT는 없습니다.

1. 기존 단일 Canny/Hough: 공개3입력21변형의 최대 상대 차이0.30349°. 첨부는4개 거절, −15°추가 영상에서14.78485°차이이며 기존 교차검증도 낮은 신뢰도로 표시했습니다.
2. L2 Canny와 다중 평활/임계값을 항상 적용한 실험: 첨부 상대 차이는 최대0.47298°로 작아졌지만 기준 각도가 약−40.63°로 바뀌었습니다. 수동 두 점의 약−44.61°와 불일치합니다. **일관성만 보고 개선으로 채택하면 잘못된 결론**입니다. 수동선도 전문가 GT는 아닙니다.
3. 채택한 제한적 보조: 기존 추정이 충분히 합의하면 유지. 실패/불일치 때만 σ4/6/2, Canny L2 10/25 또는5/12를 탐색. 보조 후보는 구조 텐서와2°미만 차이, coherence>.15, 선 분산<3°를 모두 만족해야 높은 신뢰도 제안입니다. 그 외 제안은 명시적 경고 상태입니다. 원래도 모든 회전은 사용자 확정이 필요합니다.

최종: 공개3입력21변형은 기존 결과 보존(최대0.30349°). 첨부 원본과 −60°추가는 기존 제안 유지. 나머지5변형은 제안은 가능하지만 상대 차이3.25595~3.98711°이고 **모두 낮은 신뢰도**입니다. 자동 수평 보정 성공으로 세지 않습니다. 기준점/레이어 경계/ROI 재선택이 필요합니다.

별도의 알려진 합성 방향22개는 최대0.03154°차이. 균일·랜덤잡음은 거절, 동심원·체크무늬·물결은 낮은 신뢰도입니다. 종전 동심원 거절 대신 낮은 신뢰도 제안이 생긴 범위 확대도 남은 한계입니다.

첫 실행 도구에는 두 번째 프로젝트 경로 오기가 있어 종료 전 JSON 저장이 누락됐습니다. 입력 검증·단계별 저장·출처별 파일명으로 수정하고 같은 첫 프로젝트를 재실행하여 위 수치를 보존했습니다. 실패한 실행을 독립 검증 성공으로 세지 않았습니다.

증거 폴더: `real-orientation-v222-baseline`, `real-orientation-v222-l2`, `real-orientation-v222-final`, `real-orientation-v222-guarded`, `orientation-controls-v222-guarded`. final은 안전 기준 강화 전, guarded는 최종 첨부 판정입니다.

## 사용 의도와 남은 차이

| 요구 | 현재 | 남은 작업 |
|---|---|---|
| Grid/ML 분리, 선택형 denoise | 분리되어 동작. profile도 독립 양성점 | ML명칭은 비지도/영상처리도 포함, 학습 분류로 오해하지 않기 |
| 여러 이미지 분할 먼저 | 단일/일괄 SAM 후 레이어 미배정 유지 | 이미지별 최적 프롬프트 자동 선택 미구현 |
| 필요한 mask만 GT·계측 | 선택 scope, unknown, 별도 검수 및 전체 target 미리보기 | 선택 target의 binary GT와 semantic layer GT 구분 |
| 얇은 층 자동화 | 합성 profile 개선, 공개 실측 정확도 미검증 | 실제 전문가 GT로 비교, 학습/다중 ROI 전략 후보 |
| 자동 수평 | 층/대표점/수동선 및 영상 보조 방식 | 주석 많은 첨부 변형5개 낮은 신뢰도. 완전 자동 아님 |
| 프롬프트 재사용 | 개별 normalized/ECC미리보기 | preset 일괄 전송·실패 격리 미구현 |

## 조사한 공식 자료와 다음 선택지

- [SAM 공식 automatic mask generator](https://github.com/facebookresearch/segment-anything/blob/main/segment_anything/automatic_mask_generator.py): 명시 점 grid/다중 crop/필터 경로를 확인했습니다. 더 작은 ROI crop 추론은 다음 비교 후보이지 이번 profile 비교에서 실행한 설정은 아닙니다.
- [SciPy find_peaks](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.find_peaks.html): prominence/간격 API를 이용한 자체 프로파일 구현. 외부 프로젝트 코드를 복사하지 않았습니다.
- [OpenCV Canny](https://docs.opencv.org/4.x/da/d22/tutorial_py_canny.html), [Hough](https://docs.opencv.org/4.x/d9/db0/tutorial_hough_lines.html): L2 gradient와 선 검출 원리 참고. L2를 쓴다는 사실만으로 방향 정확도가 보장되지 않습니다.
- [μSAM 공식 저장소](https://github.com/computational-cell-analytics/micro-sam): 현미경용 fine-tuning/자동 분할 기능. 생물 현미경 중심 공개 사례를 재료 TEM 성능으로 간주하지 않았습니다. 학습 데이터/가중치·회사 반입 검토가 필요하며 이번에는 설치/실행하지 않았습니다.
- [HQ-SAM 공식 저장소](https://github.com/SysCV/sam-hq): 정밀 경계용 모델 대안. 별도 가중치/호환성/라이선스 검토 및 회사 TEM 평가가 필요하며 이번에는 실행하지 않았습니다.

현장 이미지와 전문가 GT 없이 회사 정확도, 계측 오차 범위, 물질별 자동 GT 완성도를 보증할 수 없습니다.
