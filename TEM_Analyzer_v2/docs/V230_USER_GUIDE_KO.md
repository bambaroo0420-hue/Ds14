# v2.3.0 사용 안내 — 무엇을 선택하고 무엇을 바꾸는가

## 먼저 알아둘 것

이 도구의 순서는 **이미지/축척 → SAM 후보 → 필요한 mask 배정 또는 선택 집합 → 선택적 GT → 회전/계측**입니다. 모든 층을 분류하거나 경계 GT를 완료해야 계측할 수 있는 것은 아닙니다. SAM 결과는 후보이며, 배정과 GT 검수 확정도 서로 다른 작업입니다.

상단 이미지 선택은 현재 작업 영상입니다. 상단 레이어 선택은 배정/색 변경 대상이며 회전 기준 레이어·측정 대상은 4번 페이지에서 각각 지정합니다. 가운데 상태 줄의 `편집 A #번호`는 브러시·단일 경계 편집 대상입니다. 다중 선택 개수와는 다릅니다. 원본 파일은 보존됩니다.

## 1. 화면과 선택

| 분리 / 도킹 | 왼쪽 패널을 띄우거나 제자리로 돌립니다. 분리 후 제목을 드래그, 오른쪽 아래 모서리로 크기를 조절합니다. |

| 새 레이어 / 이름 수정 / 색 | 새 ID와 서로 다른 기본색을 생성합니다. 이름만 바꾸면 색은 유지합니다. 색을 바꿔도 semantic ID는 바뀌지 않습니다. |

| 레이어 잠금 | 해당 레이어의 마스크 수정/배정·해제를 막습니다. 다른 마스크 브러시도 잠긴 층 픽셀을 침범하지 않습니다. |

## 2. OCR, 제외 영역, 축척

1. `현재 이미지 자동 검출`은 문자와 바를 **제안**합니다. 아직 제외 적용/축척 확정이 아닙니다.
2. 표와 원본 위 박스를 확인합니다. 숫자·단위와 바를 함께 포함해야 합니다. 잘못 찾은 행은 체크를 해제합니다.
3. 놓쳤다면 `놓친 문자…보완`을 열고 ROI를 그립니다. `ROI 대비·확대 OCR 재검출`은 그 구역을 국소 대비/확대로 다시 읽고 원본 좌표로 복원합니다. 같은 추론을 무조건 반복하는 기능이 아닙니다.
4. OCR로도 안 잡히면 종류(하단 문자/숫자+단위+바/배율)를 지정하고 수동 박스를 추가합니다. 표 번호는 1부터이며 빈 값이면 추가, 입력하면 그 행의 box를 교체합니다. 수동 box 자체가 nm/px를 만들지는 않습니다.
5. `검출 박스를 제외 영역으로 적용`은 선택한 영역만 분석에서 제외합니다. **이미 확정한 축척을 덮어쓰지 않습니다.**
6. 축척은 이미지별 스케일 설정에서 바 양 끝+실제 길이를 저장하거나, 일괄 스케일 표에서 유효한 검출 제안을 저장한 뒤 별도로 확정합니다. 실패/모호함을 단순 확인 버튼으로 성공 처리하지 않습니다.

제외 영역은 원본에서 crop/delete되지 않습니다. 현재 SAM 전처리는 가까운 유효 픽셀로 채우고 결과/학습 valid에서 제외합니다. 이 인공 패턴은 근처 SAM에 영향을 줄 수 있습니다. 글자가 없는 내부 **독립 ROI**로 추론하는 것이 별도 선택지입니다. 자동 footer strip crop·여러 inpainting 방법 비교 선택은 이번 버전에 없습니다. 템플릿은 기본 비활성인 이전 방식이며 필요할 때만 켭니다.

## 3. SAM / Manual / Recipe

### 기본 분할

모델 경로/ViT 종류/장치를 맞춰 `모델 로드` → Grid 점 만들기 → 필요 시 ML/에지 점 추가 → +/−점/box → `준비한 프롬프트로 SAM 실행`입니다. Grid 생성·필터 미리보기·ML 제안은 SAM 마스크 생성과 구분됩니다. Canny/Sobel/Scharr/profile는 영상처리, K-means는 비지도 군집입니다. 물질 분류기가 아닙니다. 원본/SAM/경계/프롬프트 전처리는 서로 구분합니다.

### 여러 수동 객체

한 객체의 점/box를 그린 후 `현재 입력 → 새 그룹`을 누릅니다. Manual 1을 담으면 편집점은 비워지고 다음 객체를 Manual 2로 담을 수 있습니다. ROI 제한을 쓰려면 ROI도 그리고 체크합니다. 그룹 저장은 프로젝트 저장, 보라색 Recipe 저장은 재사용 preset 저장입니다. 서로 대체하지 않습니다.

`선택 그룹 → 캔버스 편집` 후 점을 고치고 `편집값으로 선택 그룹 갱신`을 누릅니다. 입력 잠긴 그룹은 먼저 잠금을 해제하세요. 잠긴 그룹도 SAM 추론은 가능합니다. 브라우저를 닫기 전에 그룹 저장을 누르세요. 저장하지 않은 그룹은 같은 화면 세션에서 이미지별로 임시 보관됩니다.

준비한 SAM 실행은 현재 Grid/ML 점, 현재 편집 수동 객체, 체크된 Manual 그룹을 실행합니다. 그룹 편집점을 그대로 남기면 별도 객체로 중복 실행될 수 있으므로 그룹 갱신/담기 후 비워진 상태를 확인하세요. 결과 출처는 `manual-group`, `transferred-group` 등으로 기록됩니다.

### ROI

- `부모 없이 ROI 확대 분할`: 독립 ROI. 수동 +/−점/box → 수동 미리보기 → 확인 후 새 후보 저장. 후보 1/2/3은 **하나의 객체에 대한 대안**입니다.
- 같은 창의 `독립 ROI 자동 후보`: ROI만 지정하고 Grid/ML/Grid+ML 및 IoU/Stability/NMS를 조절하여 여러 자동 후보를 제안합니다. 개별 보기를 확인하고 필요한 체크 행만 저장합니다. 수동점은 자동 ROI 모드에 포함되지 않습니다.
- `선택 후보 내부 ROI 재분할`: 결과를 부모 mask 안으로 제한하는 기존 기능입니다. 잠긴 부모를 바꾸지 않습니다.
- 보라색 `이 ROI·점·box를 새 Manual 그룹에 담기`: 입력을 재사용합니다. 부모 ID는 출처 기록일 뿐 대상 영상의 부모를 추측하지 않습니다. 재사용 그룹은 독립 ROI 추론입니다. 사전정렬 옵션이 켜진 ROI의 Recipe 저장은 아직 지원하지 않아 차단합니다.
- ROI 가장자리는 잘린 경계일 수 있어 기존 crop guard가 GT/계측에서 제외합니다. crop으로 잘린 선을 물질 경계로 해석하지 마세요.

### 일괄 Recipe v2

Recipe는 기존 v1 preset을 지우지 않고 읽습니다. 새 저장은 그룹·ROI·자동점 정책·feature 설정·기준 SAM 전처리·모델 정보도 기록합니다. 예전 자동점은 Grid/ML 출처가 섞여 있으므로 거꾸로 추정해 나누지 않습니다.

| 정책 | 대상 영상에 준비되는 입력 |
|---|---|
| 저장 좌표 재사용 | 저장 자동점과 수동 그룹의 좌표 변환 |
| 대상별 Grid | Grid 재생성 + 변환된 수동 그룹 |
| 대상별 ML/에지 | 저장 feature 설정으로 새 점 계산 + 변환된 수동 그룹 |
| 대상별 Grid+ML | 위 두 자동점 + 변환된 수동 그룹 |

5번 페이지에서 이미지 범위 선택 → preset 준비만 실행 → **각 이미지 미리보기** → 검토 확정 → SAM 프롬프트를 `저장·검수한 재사용 프롬프트`로 선택 → SAM 단계만 실행합니다. 일반 Grid/ML 일괄 메뉴를 선택하면 Recipe 수동 그룹은 포함되지 않습니다. 준비 이후 입력이 바뀌면 다시 준비/검토해야 합니다. 실패 시 이전 draft로 몰래 실행하지 않습니다.

정규화 좌표는 영상 정합이 아닙니다. ECC는 작은 회전/이동용이고 반복 셀 대응 오류가 가능합니다. 대상 영상의 SAM 전처리는 대상 설정을 사용합니다. Recipe의 기준 전처리 기록으로 자동 덮어쓰지 않습니다.

## 4. 경계 GT

먼저 A 후보/인접 B 또는 레이어 A/B를 선택합니다. GT 진단에서 빨강 겹침·노랑 미지정·흰 사선 보호를 봅니다. 노랑 전체가 채워야 할 틈은 아닙니다.

| 기능 | 논리와 적용 절차 |
|---|---|
| 단일 공유 경계 미리보기 | A 외곽 법선의 안/바깥 탐색 폭에서 gradient와 DP를 계산. 흰 원래 경계, 주황 피크, 청록 DP를 비교. 보호 제약까지 반영한 실제 마스크와 선은 다를 수 있습니다. |
| 경계 클릭→프로파일 / 지점 고정 / 부분 구간 | 원하는 외곽 지점을 선택해 실제 gradient를 보고 이동량을 고정하거나 해당 구간 설정을 바꿈. 설정 후 다시 미리보기, 확인 후 적용. |
| 레이어 전체 공유 경계 | 인접·비인접 충돌을 먼저 검사. 허용 폭/작은 틈 내 자동 제안. 제안 적용 후 다시 마스크 검수. |
| 두 층 빈틈 Gradient/DP | A/B 사이 단일 구간의 실제 밝기 변화에서 공통선을 찾고 빈 픽셀을 양쪽에 배정. 최대 폭은 1~200px로 조절. 40px 틈도 50px 설정으로 검토 가능. |
| 빈틈 확인 체크 | 제3의 층/공극이 아니라 분할 누락인지 사용자가 검수하는 항목. 복수 피크·큰 틈을 자동 정답으로 간주하지 않음. 확인 전 적용 불가. |
| 브러시 새 후보 저장 | A만 수정하여 새 후보를 만듭니다. 부모 교체/추가/분할 방식으로 확정하세요. 다른 층 잠금과 보호 픽셀을 유지합니다. |
| 배경/미지정/불확실/제외/보호 | 브러시로 영역을 그리고 상태를 적용. 배경은 실제로 필요 없는 영역으로 판단한 경우만 지정하세요. |
| Full semantic 진단 | 겹침·미지정·불확실·미검수와 export 유효량을 검사. 미완료일 때 GT 다운로드는 부분 GT임을 경고합니다. |

서로 다른 클래스는 하나로 합쳐 클래스 ID를 없애지 않습니다. 제3층이면 새 레이어를 만들어 해당 영역을 분할/수정합니다. 내부 구멍은 보존합니다. 구멍 일괄 채우기, 분기/폐곡선 모든 형태의 자동 bridge, 검수 없이 full semantic 완성은 지원하지 않습니다. 신규 빈틈 bridge는 현재 **단일 이미지 검수 흐름**이며 기존 일괄 경계 단계와 구분됩니다.

GT ZIP의 semantic만 단독 학습하지 말고 valid를 같이 사용하세요. 원본 labels에는 unknown/uncertain/excluded 코드가 있고, Lab 도구별 ignore-label 계약은 별도 확인해야 합니다. 사용자 학습 decoder의 실제 가중치 파일은 이번 검증에 제공되지 않았습니다.

## 5. 회전·계측

회전 기준 레이어와 측정 레이어는 다를 수 있습니다. 선택 집합을 사용하면 각 영상에서 같은 집합 ID를 먼저 저장하세요. GT는 불필요합니다. 기준 경계(상/하/좌/우), ROI 또는 대응점을 지정하고 제안 → 실제 기준점/피팅선 보기 → 확정합니다. 두 점 잔차 0은 정확도 증거가 아닙니다.

두께는 회전 후 수직 길이, CD는 회전 후 수평 길이입니다. 시작/끝/간격은 **회전 좌표계 px**입니다. 데이터에는 원본·회전 끝점과 정/역변환이 같이 저장됩니다. 곡면 국소 법선 두께가 아닙니다. 연결 객체 중앙 비율/최소 길이/다중 교차/프레임 끝점 제외는 명시적으로 선택하고 제외 행을 보존합니다.

`계측선·끝점 보기`는 실제 사용한 mask와 표본을 보여줍니다. 표 행 클릭은 해당 선 하나와 수치를 보여줍니다. 전체 그림은 가독성 때문에 약 150선으로 간추리며 ZIP 데이터는 전부 남습니다. 원본과 회전 좌표 그림의 점·선을 비교하세요. PNG 저장은 발표용 근거 그림이며 재료 GT 인증이 아닙니다.

일괄 회전 제안과 일괄 확정 이후 계측을 별도로 실행합니다. 두께/CD는 각각 실행하며 각 방향 최신 결과를 보존합니다. 입력 변경으로 만료된 결과는 다시 계산해야 합니다. 다른 mask로 임의 대체하지 않습니다.

## 6. 오류/설치/수정 위치

가상환경·패키지는 매번 다시 설치하지 않습니다. 새 shell에서 같은 `.venv`를 사용하거나 `start_windows.bat`로 실행합니다. 회사의 오프라인 모델 설치/체크포인트 링크는 README와 INSTALL_KO.md를 따르세요. WinError 5/32, 업로드 read, uvicorn 누락은 기존 진단/저장 재시도 안내를 유지합니다. 실행 중 프로젝트 폴더를 동기화하거나 같은 project.json을 여러 서버에서 동시에 열지 마세요.
