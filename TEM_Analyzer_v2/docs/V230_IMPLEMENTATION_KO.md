# v2.3.0 구현·검증 기록

2026-10-01. v2.2.9 및 보관 중인 Gradient+DP/잠금 검토본을 기반으로 만든 **v2.3.0 시각화 워크벤치**입니다. 사용자가 승인한 구현 작업의 변경점과 실제 검증을 기록합니다. 아래 구현 범위의 소스/테스트를 제공하며, 대화에서 논의한 모든 자동화가 완성되었다는 의미는 아닙니다. 기존 프로젝트·Recipe·원본은 보존합니다.

## 목적과 불변 조건

유사 TEM 영상 여러 장을 먼저 SAM 분할하고, 필요한 마스크만 레이어/선택 집합에 배정한 다음 선택적으로 GT를 만들고 회전·두께/CD를 계측합니다. GT는 회전·계측의 선행 조건이 아닙니다. 레이어 이름/표시색과 semantic 클래스 ID를 구분합니다. 빈 픽셀은 자동 배경이 아니며, 겹친 서로 다른 물질은 한 클래스로 합치지 않습니다. 원본은 항상 보존하고 추론·보정 결과는 검토 대상으로 취급합니다.

## 명확히 구분할 한계

- 모든 물질을 자동 식별하는 full semantic 모델이 아닙니다. unknown/uncertain/conflict가 남으면 완전한 GT로 주장하지 않습니다.
- Gradient+DP 빈틈 보정은 선택 A/B 사이 한 경계 가정입니다. 제3층·내부 구멍·복잡한 다중 연결 구조를 무조건 채우지 않습니다.
- 회사 영상·전문가 GT·사용자 학습 decoder 체크포인트가 없으므로 회사 정확도나 실제 학습 가중치 호환성을 확정할 수 없습니다.
- feature(Canny/Sobel/Scharr 등)는 영상처리 기반 프롬프트 제안이지 물질 분류 학습 모델이 아닙니다.
- 계측은 회전 후 수직 두께/수평 CD입니다. 곡면의 국소 법선 두께와는 다릅니다.
- 미구현 요구는 최종 결과에서 별도로 남기며 UI 시안을 구현 완료로 세지 않습니다.

## 검증과 배포 기록

### A. 세부 변경

#### A1. 화면·선택·레이어

- 원본 캔버스, 후보/레이어 배정 패널, 단계별 설정 패널로 나누었습니다. 이미지·레이어 선택과 현재 영상/선택 개수/편집 A/도구를 구분해 표시합니다.
- 후보 배정 패널을 캔버스 가까이 옮기고 분리·도킹·이동·크기 조절·위치 잠금을 추가했습니다. 위치 잠금과 레이어 편집 잠금은 다른 기능입니다.
- 다중 선택한 후보 전체를 동시에 표시합니다. 전체 레이어 보기에는 배정된 후보들만 포함합니다. Ctrl/Shift/전체 선택, 드래그 배정, 배정 해제, 삭제, Undo/Redo는 유지합니다.
- 레이어 생성 시 ID 기반으로 서로 다른 색을 부여하고 색 변경을 지원합니다. 이름 변경 시 기존 색은 보존하며 semantic ID는 변경하지 않습니다. 레이어별 포함 후보 번호/이름/개수도 표시합니다.
- 브라우저 기본 prompt에 의존하던 템플릿 생성/복사, 레이어 이름, 후보 이름 입력을 HTML 대화상자로 바꾸었습니다.
- 경계 적용 후 비활성화된 옛 후보가 선택되어 화면이 비던 문제를 수정했습니다. GT 진단 수치도 입력 갱신 후 오래된 값을 계속 보여주지 않습니다.

#### A2. Manual 그룹·Recipe와 일괄 분할

- Manual 1/2/...에 각 객체의 양성·음성점, box, 선택적 ROI를 독립적으로 저장하고 각 그룹을 별도 SAM 호출로 실행합니다. 한 그룹의 여러 점과 여러 독립 객체를 혼동하지 않습니다.
- 그룹 저장/불러오기/갱신/삭제/입력 잠금을 추가했습니다. 서버가 잠긴 그룹의 삭제·내용 변경을 차단합니다. 이미지 전환 시 미저장 그룹은 같은 브라우저 세션 내 임시 보관합니다.
- Recipe schema v2에 그룹·ROI·자동점 정책·Grid 크기·feature 설정·기준 SAM 전처리·모델 정보를 기록합니다. 기존 preset은 기본 좌표 재사용 정책으로 읽습니다. 모델 정보는 기록용이고 모델/가중치를 자동 교체하지 않습니다.
- 자동점은 저장 좌표 재사용, 대상별 Grid, 대상별 feature, 대상별 Grid+feature 중 선택합니다. 수동 그룹은 변환해 함께 사용합니다. Recipe 미리보기 후 다시 저장해도 정책/feature 설정이 유지되도록 보완했습니다.
- 일괄 실행은 **준비 → 이미지별 점/box/그룹 미리보기 → 검수 확정 → SAM 실행 → 별도 레이어 작업**입니다. 기존 일반 Grid/feature 일괄 실행은 그대로이며, Recipe 그룹을 쓰려면 검수된 재사용 프롬프트 모드를 선택해야 합니다.
- 변환 후 영상 밖/제외 영역의 수동점이나 ROI는 조용히 버리지 않고 오류로 중단합니다. SAM 전처리 변경도 검수 만료 판단에 포함합니다.
- ROI 편집창의 점/box/ROI를 그룹에 담는 보라색 버튼을 추가했습니다. 부모 ID는 출처 기록입니다. 다른 영상의 부모 mask를 추정하여 자동 교체하지 않습니다. 사전정렬 ROI 입력의 Recipe 저장은 아직 차단합니다.

#### A3. 독립 ROI 후보 생성

- 기존 수동 ROI의 후보 1/2/3은 한 객체의 대안이라는 점을 명시했습니다.
- 별도로 **독립 ROI 자동 후보**를 추가했습니다. Grid/feature/혼합, Grid 수, 예측 IoU, Stability, NMS를 조절합니다. feature 방법/노이즈 제거 설정은 SAM 화면의 설정을 사용합니다.
- 후보를 임시 보관하고 원본 좌표 미리보기·개별 보기·체크한 후보 저장을 지원합니다. 저장 전 입력 fingerprint, 미리보기 유효기간, 중복 저장을 확인합니다. 원래 후보를 덮어쓰지 않고 새 미검수 후보를 만듭니다.
- 실제 추론은 ROI 내부에서 수행하며 결과를 원본 크기로 복원합니다. ROI 밖 픽셀은 생성하지 않습니다. ROI 잘림 경계는 기존 GT/계측 crop guard로 보호합니다.

#### A4. OCR·제외·축척

- 놓친 부분을 ROI로 지정해 대비 보정/확대 OCR을 수행하고 좌표를 원본으로 복원합니다. ROI 밖 기존 OCR 결과를 보존합니다.
- 수동 문자/배율/하단 문자/scale+문자 박스를 추가하거나 특정 제안 행의 box를 교체할 수 있습니다. 여전히 적용 전 제안이며 수동 box만으로 축척은 생성되지 않습니다.
- **제외 박스 적용과 축척 저장/확정을 분리**했습니다. OCR 제안에 축척 실패가 있더라도 제외 적용이 이미 확정한 축척을 지우거나 덮어쓰지 않습니다.
- 현재 제외 방식은 원본 유지, 가까운 유효 픽셀 채움, 결과 valid 제외입니다. 주변 분할에 인공 패턴이 영향을 줄 가능성은 남습니다. 자동 strip crop/inpainting 선택은 새로 구현하지 않았습니다.

#### A5. 경계 GT·잠금

- GT 진단은 겹침 빨강, 미지정 노랑, 불확실 보라, 제외 분홍, 배경 회색, 보호 흰 사선으로 표시하고 픽셀 수/미검수 후보를 보여줍니다. 노랑 전체를 틈으로 해석하지 않습니다.
- 보관본 Gradient+DP 빈틈 보정을 통합했습니다. 명시한 두 층 사이의 단일 경계 가정으로 공통 경로를 제안하고 양측 mask를 그 선까지 확장합니다. 허용 폭은 1~200px, 실제 gradient 프로파일/제안 변경 픽셀/검수 확인 후 적용합니다.
- 겹침은 기존 충돌 진단과 공유 경계 기능으로 분리합니다. 신규 gap bridge는 겹친 입력을 먼저 거부합니다. 서로 다른 물질 클래스를 하나로 합쳐 충돌을 숨기지 않습니다.
- 제3층 의심, 약한 신호, 보호 영역, 다른 층, ROI 절단 영역 및 내부 구멍을 보존합니다. 폭을 크게 설정하는 것은 큰 틈의 검토 허용이지 실제 재료가 없다는 자동 판정이 아닙니다.
- 브러시 대상의 원래 레이어 잠금을 편집 후보의 부모 계보까지 추적합니다. 다른 잠긴 층 픽셀을 침범하지 않습니다. 임시 잠금이 영구 수동 보호로 저장되던 문제도 수정했습니다.
- full semantic 진단은 유효 영역이 있고 충돌/unknown/uncertain/미검수 배정 mask가 없어야 준비됨으로 표시합니다. 이 조건은 데이터 완결성이지 재료 정답 정확도 인증이 아닙니다.

#### A6. 회전·계측 근거

- 회전에 실제 사용한 mask, 기준점, 피팅 중심/방향/가중치/잔차를 저장하고 원본/회전 좌표 그림에 표시합니다. 표본 두 개면 잔차 0이 정확도 증거가 아니라는 경고를 추가했습니다.
- 계측은 실제 저장된 양 끝점으로 선을 그립니다. 결과 표 행을 선택하면 해당 표본 한 개를 표시하고, 전체 보기는 가독성을 위해 약 150선으로 간추립니다. 전체 수치는 별도 데이터에 보존합니다.
- 근거 창은 이미지가 로드된 후 표시합니다. 입력이 달라진 과거 결과는 보여주기 전에 만료 검사합니다. PNG 저장은 발표용 근거 자료입니다.
- 선택 mask 집합 기반 회전/계측, 두께/CD 양방향 저장, 좌표 정/역변환, 기존 일괄 제안·확정·측정은 유지합니다. GT를 선행 조건으로 만들지 않았습니다.

| 첨부 45° 도판 OCR | 전체 OCR 약 17.46초, 문자/scale 제안 6영역. `5 nm`+약 70.013px 바에서 약 0.0714153 nm/px 제안 | 화학식 아래첨자 인식 오류와 TiN의 footer 종류 오분류가 남음. 검출 box는 확인 필요 |
| 국소 OCR | scale ROI 재검출 약 0.49초; 수동 box 보완, 제외 적용 후 확정 축척 보존 | 원본도 보존. 모든 글자·화살표/도판선을 자동 제거한 결과가 아님 |
| 40px 빈틈 fixture | 허용 폭 50px로 16,800px 보정, 겹침 0/남은 대상 틈 0 | 합성 단일 경계 사례. 회사 다중층 정확도 아님 |
| 저장/재로드 | Manual 그룹/Recipe v2 재로드 확인 | 구버전에서 v2 그룹을 편집하는 역호환은 보증하지 않음 |

#### 계측 변동을 숨기지 않음

같은 형상의 밝기/노이즈 변형에도 mask 끝부분과 작은 교차 구간이 달라졌습니다. 전체 범위 평균을 곧바로 대표 두께/CD로 보고하면 안 됩니다.

| 시험 영상 | 두께 평균(px) | 두께 중앙값(px) | CD 평균(px) | CD 중앙값(px) |
|---|---:|---:|---:|---:|
| 2-cell 기준 | 110.698 | 132.001 | 180.766 | 223.001 |
| 밝기 0.75배 | 129.583 | 134.000 | 208.067 | 226.000 |
| 노이즈 σ=8 | 122.238 | 134.001 | 194.490 | 222.593 |

기존 중앙 구간/최소 길이/다중 교차/QC 설정을 시편 목적에 맞춰 정하고 선을 직접 확인해야 합니다. 이번 결과는 파이프라인 구동/민감도 증거이며 전문가 GT 대비 오차 평가가 아닙니다.

#### 실제 브라우저에서 확인한 조작

- 다중 선택 mask 동시 표시, 후보 이름 수정, 레이어 색/이름 변경 및 색 보존.
- 배정 패널 분리/도킹/위치 잠금, 현재 대상 표시.
- 캔버스 점으로 Manual 1/2 생성, 저장/입력 잠금, Recipe 저장.
- 합성 A/B의 GT 진단 → gap 폭 지정 → 실제 gradient 프로파일 → 검수 확인 → 적용.
- SAM 모델 로드 → 독립 ROI 드래그 → Grid 파라미터 조절 → 실제 후보 3개 표시 → 한 후보 개별 보기 → 그 한 개만 저장 완료.
- 실제 SAM 결과의 회전 전/후 근거창, 계측 전체선, 표 한 행의 CD 선/끝점.
- 브라우저 해당 테스트의 error 로그 없음. 모든 기존 버튼과 모든 조합을 이번 한 회차에서 수동 조작한 것은 아닙니다.

#### 발견·수정한 실패

1. 축척 미저장 영상에서 제외 적용 응답이 KeyError를 내던 부분을 수정했습니다. 회귀 테스트도 제외 적용이 축척을 변경하지 않는 계약으로 변경했습니다.
2. feature 재생성 함수 import 이름 오류를 실제 일괄 시험에서 발견해 수정했습니다.
3. 첫 회전 시험은 축소된 출력 캔버스 때문에 변환 box가 영상 밖으로 나가 입력 검증에 거부되었습니다. 검증을 완화하지 않고 시험 증강을 확장 캔버스로 고친 뒤 재실행했습니다.
4. 경계 보정 후 옛 비활성 후보 선택으로 화면이 비던 문제, 갱신 전 GT 수치가 남던 문제를 GUI에서 확인해 수정했습니다.
5. 2점 피팅의 매우 작은 잔차가 정확도로 오해될 위험을 발견해 경고를 추가했습니다.
6. Recipe 미리보기 후 재저장 시 자동점 정책/feature 설정 누락 가능성을 최종 검토에서 수정했습니다.

### C. 로컬 증거와 재현

영상·모델·사용자 경로가 든 시험 프로젝트/원시 로그는 공개 Git/ZIP에 포함하지 않습니다. 아래 경로는 앱 루트 기준 로컬 증거입니다.

- `test-output/v230-real-2/results.json`: 실제 SAM, 일괄 회전/계측, ROI, 원본/재로드 검사.
- 같은 폴더의 `gui-rotation.png`, `gui-measurement.png`, `gui-roi-auto.png`: 실제 브라우저 화면.
- `test-output/v230-ocr/results.json`, `global.png`, `local.png`: 첨부 도판 OCR.
- `test-output/v230-gui/`: 격리된 GT/그룹/패널 조작용 프로젝트·화면.

PowerShell에서 앱 루트로 이동한 뒤 설치한 Python 경로를 명시합니다. 아래 `$temPython`은 본인 가상환경의 경로로 바꾸세요.

```powershell
$temPython = (Resolve-Path '.venv/Scripts/python.exe').Path
& $temPython tools/check_gap_bridge.py --all --output my-v230-regression
& $temPython -m pip check
& $temPython tools/audit_v230.py --source '<19 기반 crop PNG>' --checkpoint '<SAM ViT-B pth>' --output '<새 시험 폴더>'
& $temPython tools/audit_v230_ocr.py --image '<시험 도판 PNG>' --ocr '<EasyOCR 모델 폴더>' --output '<새 OCR 시험 폴더>'
```

`check_gap_bridge.py`는 이 관리형 Windows 환경의 임시 폴더 ACL 문제를 피하기 위해 일반 작업 폴더를 테스트별로 만들고 보존합니다. OS 보안 설정을 변경하지 않습니다. 원래 `unittest` 발견 대상은 그대로이며 이 우회 사용 여부를 JSON에 기록합니다. 실제 SAM 스크립트의 기본 프롬프트는 이번 19 기반 crop 전용 시험값이므로 임의 회사 영상의 정답 프롬프트가 아닙니다.

### E. 이번 버전에 남긴 항목 — 완료로 표시하지 않음

1. mask 내부 구멍 자동 채움, 임의 외곽/분기/다중층을 모두 처리하는 gap bridge, 신규 gap bridge의 일괄 무검수 적용.
2. OCR→제외→SAM→레이어 의미 대응→GT→회전→계측을 모두 묶는 단일 통합 Recipe. 현재 확장한 것은 **SAM 프롬프트 Recipe**입니다.
3. 자동 footer strip crop, 여러 inpainting 알고리즘 선택, 화살표/도판 안내선 자동 제거. 현재 nearest-fill의 주변 분할 영향이 남습니다.
4. 45° 첨부 도판 얇은 층의 안정적인 완전 자동 SAM 분할·GT. 이번 12° 두-cell 성공으로 그 문제를 해결했다고 주장하지 않습니다.
5. 사용자 학습 decoder 실제 체크포인트 로드·수치 비교, CUDA/회사 보안 환경 설치, 회사 이미지 전문가 GT 대비 정확도.
6. full semantic 물질 자동 식별, 곡면 국소 법선 두께 측정, 모든 기존 버튼/입력 조합의 수동 전수 검증.
