## 사용 기준

1. SAM 화면에서 필요한 후보만 선택 → 같은 ID의 선택 집합으로 이미지마다 저장합니다.
2. 회전·스케일을 검토하고 확정합니다. 마스크 GT 확정은 계측의 선행 조건이 아닙니다.
3. `4 회전·계측 → 계측 표본·품질 기준`에서 전체/객체 중앙을 선택합니다. 중앙 60%는 각 연결 객체의 회전 후 투영 범위 양끝 20%씩을 제외합니다.
4. 필요하면 다중 교차 위치·원본 프레임 끝점을 제외합니다. 작은 값을 자동 이상치라고 간주하지 않습니다. 최소 길이는 사용자가 명시적으로 정할 때만 적용합니다.
5. 5번 화면에서 전체/선택 이미지를 지정하고 계측을 실행합니다. 위 옵션이 모든 대상에 동일 적용됩니다.
6. 결과에는 **실제 저장된 범위와 기준**을 표시합니다. 폼 입력값을 바꾸는 것만으로 이미 계산한 결과가 바뀌지 않습니다. 다시 측정해야 합니다.

기본값은 이전과 동일한 전체 구간/다중 교차 포함/프레임 포함/최소 길이 0입니다. 중앙 표본을 강제하지 않습니다.
연결 객체는 4-connectivity 기준이며 SAM 후보/물질 이름과 다릅니다. 여러 후보가 닿으면 같은 객체가 될 수 있습니다.

## 실제 SAM 마스크 5장 × 표본 기준 5개

`19.jpg`에서 앞서 만든 실제 SAM 결과와 확정 회전·스케일을 그대로 복사했습니다. 새로 SAM을 추론한 시험이 아닙니다.
원본·사용자 프로젝트는 변경하지 않았고, 모든 레이어 배정을 해제한 테스트 프로젝트만 사용했습니다.
3-cell의 가운데 마스크는 선택하지 않아 unknown으로 남습니다.

평균 nm (괄호는 유효 표본 수):

| 이미지 | 전체 | 중앙 80% | 중앙 60% | 중앙 60% + 다중 교차 제외 |
|---|---:|---:|---:|---:|
| 1 cell, 0° | 165.435 (19) | 166.051 (15) | 165.486 (12) | 165.486 (12) |
| 1 cell, +7° | 137.304 (23) | 166.301 (15) | 165.855 (11) | 165.855 (11) |
| 3 cell, 0° | 158.803 (46) | 159.324 (38) | 156.702 (28) | 162.963 (26) |
| 3 cell, +7° | 143.421 (40) | 163.875 (30) | 163.226 (24) | 163.226 (24) |
| 3 cell, −8° | 155.350 (39) | 164.323 (30) | 163.691 (24) | 163.691 (24) |

5번째 기준은 마지막 열 + 프레임 끝점 제외이며 이 5장에서는 동일 결과였습니다.

핵심 발견:

- 1-cell +7° 전체 측정에는 약 0.595 nm의 아주 짧은 교차 구간이 섞였고 평균 137.304 vs 중앙값 165.351 nm였습니다.
- 중앙 60% + 다중 교차 제외에서 같은 1-cell 0°/7° 평균 차이는 0.369 nm로 줄었습니다.
- 3-cell 0°/7°/−8° 평균 범위는 전체 15.382 nm에서 마지막 기준 0.728 nm로 줄었습니다.
- **중앙 60%만으로는 3-cell 0° 문제가 해결되지 않았습니다.** 구멍 때문에 중앙에도 짧은 분절이 남아 156.702 nm였습니다. 다중 교차 제외를 켜야 162.963 nm가 됐습니다.
- 이는 같은 mask의 측정 정의에 대한 민감도·재현성 비교이지 실제 물질 두께 정확도 증거가 아닙니다. 실제 두께는 균일하다는 가정도 자동으로 하지 않습니다.
- 각 정책에서 원시 행 개수 유지, 제외 행의 최종 nm 비움, raw_length_nm 및 사유 출력, 부분 GT unknown 유지 확인. 25/25 이미지 계측 완료, 5개 ZIP 확인.

재현:

```powershell
python tools/validate_measurement_sampling.py --source test-output/selected-scope-v220 --output test-output/sampling-new
```

기존 출력 디렉터리를 덮어쓰지 않습니다. 입력은 앞선 선택 집합 실제 SAM fixture가 있어야 합니다.
증거는 로컬 `test-output/sampling-v221/results.json`, 정책별 ZIP. 영상·mask·결과 ZIP은 GitHub에 올리지 않았습니다.

## 영상 보조 방향의 대조 시험

512×512 합성 평행층에 −80, −60, −45, −25, −7, 0, +7, +25, +45, +60, +80° 각도와 잡음 표준편차 0/20을 적용했습니다.

- 알려진 방향 22/22 제안, 최대 절대 각도 오차 **0.03154°**.
- 균일/랜덤 잡음/동심원 3개는 직선 부족 또는 합의 부족으로 거절.
- 체크무늬와 물결 2개는 각도가 나오지만 `reliable_proposal=false`. UI에도 교차검증 불일치 경고를 추가했습니다.
- 이미지 방향 모드는 항상 사용자 확인 전 제안입니다. 조명·격자·화살표에 끌릴 수 있으며 선택 mask의 물질 경계를 검증한 것으로 취급하지 않습니다.
- 실제 TEM 확대·회전·음성 이미지에 대한 일반화는 다음 반복 검토 항목입니다. 합성 각도 시험만으로 첨부 SAM 경계 실패를 해결했다고 하지 않습니다.
