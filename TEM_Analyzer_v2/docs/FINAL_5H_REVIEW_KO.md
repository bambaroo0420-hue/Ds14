## 결론

**사람이 대상 마스크와 기준을 검토하는 반자동 GT·회전·두께/CD 도구로는 사용자 의도에 가까워졌습니다. 모든 TEM 영상에서 무검수로 정답 GT와 정확한 계측을 만드는 도구는 아닙니다.** 실제 모델·API·GUI에서 경로가 실행되는 것과 물질 경계 정확도를 분리해 평가했습니다. 회사 영상과 전문가 GT가 없어 생산 정확도를 인증하지 않습니다.

## 자동화할 때 반드시 고정할 계측 기준

1. 같은 물리적 계면과 같은 의미의 구간을 회전 기준으로 정합니다. 단일 mask는 경계 여러 점을 직선 fit, 반복 cell은 각 cell의 대응 위치를 사용합니다. 임의 centroid나 편한 두 점이 물리적으로 동일한 기준이라는 보장은 없습니다.
2. 회전 기준과 측정 대상/구간을 분리합니다. 회전 후 두께는 세로, CD는 가로 교차 길이입니다. 곡면의 국소 법선 두께와 같지 않습니다.
3. cell별 중앙 비율, 표본 간격, 최소 길이, 프레임 끝점/다중교차 제외 정책을 고정합니다. 일괄 평균만 보지 말고 유효 수·무효 이유·분포도 확인합니다.
4. nm/px, 회전, 제외 영역, mask 변경 시 결과를 만료시키고 재계산합니다. 변환 행렬과 원본 끝점까지 보존합니다.
5. 후보 score나 기준 간 합의는 전문가 GT가 아닙니다. 어긋난 기준은 검수 대상으로 남깁니다.

## 장점·보완 우선순위

장점은 원본 보존, 선택영역만 처리, GT와 계측 분리, 후보 비교와 검수 gate, 실패 재시도, 입력 만료 검출 및 재현 가능한 출력입니다. 단점은 얇은 층의 SAM 분할 편향, 많은 수동 판단, CPU 추론 시간, OCR 주석 잔존, 여러 물질/형상에 대한 무GT 평가 한계입니다.

| 우선순위 | 다음 과제 | 완료 판단 기준 |
|---|---|---|
| P0 | 회사 비식별 영상+전문가 경계/축척 GT, 허용 오차·반복 측정 protocol 합의 | 물질별 경계오차·두께 bias/분산·실패율을 별도 holdout에서 측정 |
| P0 | 3px급 얇은층, 분절/다중교차 CD 경고 및 객체별 검토 | 작은 유효 수의 불안정 평균을 자동 통과시키지 않음 |
| P1 | 독립 ROI+대응점+계측구간을 이름 있는 일괄 레시피로 저장 | 영상마다 ROI/스케일이 바뀌어도 대상 일치 검수 및 실패 격리 |
| P1 | domain 적합 모델/HQ 경계·현미경 특화 접근 비교 | 공식 가중치·라이선스 확인 후 동일 GT로 비교. 조사만 한 모델을 구현 완료로 표기하지 않음 |
| P1 | 국소 법선 두께와 여러 위치/레이어 측정 이력 | 현재 세로 두께와 정의를 분리하고 알려진 곡면 대조군 통과 |
| P2 | OCR 누락/기호·화살표 보조 검출, 회사 촬영형식 profile | 재료가 포함된 영역을 과도하게 제외하지 않는 recall/false exclusion 평가 |

조사한 외부 방법과 출처는 각 버전 보고서에 있습니다. 이번 작업에서 회사용 모델을 새로 학습하거나 전문가 GT를 얻지는 않았습니다. 알려진 생성 변환·전문가 없는 공개 영상·첨부 영상의 결과를 서로 대체하지 않습니다.
