# v2.1 변경 기록 — 2026-09-30

- 회사 오프라인 설치·공식 체크포인트·가상환경 재사용 문서. 실행 BAT는 설치를 반복하지 않음.
- OCR 전체 영상 검출: 바와 길이 문자를 한 박스, 상단 배율, 하단 긴 문구를 별도 박스로 제안.
- 짧은 문자 획의 스케일바 오검출 방지, 기울어진 바 PCA 길이 추정, OCR 여백 허용.
- 기존 고정 위치 템플릿은 기본 비활성화. 켜기/끄기 스위치와 OCR 영역을 독립 저장.
- 레이어 합집합·인접/비인접 충돌 검사·허용 폭 내 공유 경계 Gradient+DP 보정.
- 레이어 배정과 마스크 검수 분리. 미지정 후보는 배경으로 채우지 않음.
- GT·경계 보정 없이 SAM → 레이어 → 회전 → 두께/CD 경로 지원.
- 회전 기준 자동 선택: 단일 마스크의 중앙 경계 구간 / 여러 마스크의 경계 대표점.
- 직접 지정 ROI·대응점도 지원. 원본↔정렬 3×3 변환과 역변환, 원본 보존.
- 잠정 계측 상태, 제외·충돌 무효 결과, 좌표 변환·CSV/JSON/PNG ZIP 출력.
- 일괄 처리·진행률·취소·부분 실패·실패 단계 재시도·서버 재시작 중단 상태 보존.
- Ctrl/Shift 다중 마스크 선택·레이어 드래그·다중 삭제·Undo 및 이미지 휴지통 복원.
- 브라우저 native confirm 대신 비동기 HTML 확인창. 원본/회전 큰 비교창.
- 19.jpg crop/회전/반복 cell 예제 생성과 실제 SAM/OCR 검증 도구.
- 계산/서비스/API/UI 모듈 및 한국어 유지보수·검증 문서 추가.
